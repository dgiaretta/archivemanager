# oais-structure-kaitai ގެ ނޯޓުތައް

މި މޮޑިއުލުން **Kaitai Struct** އާންމު `StructureNode` މޮޑެލާ ގުޅުވާ. އެއިން
Kaitai Struct ގެ Java ރަންޓައިމް `io.kaitai:kaitai-struct-runtime:0.11` (MIT
ލައިސަންސް، Maven Central އިން) ބޭނުންކުރޭ، އަދި Kaitai Struct ކޮމްޕައިލަރ 0.11
އިން ޖެނެރޭޓްކުރި ކްލާސްތަކާ ދެކޮޅަށް ޗެކްކޮށްފައި.

## ފޯމެޓެއް ތަފްސީލުކުރާ ގޮތް

Kaitai Struct ތަފްސީލަކީ `.ksy` ފައިލެއް (YAML): ފީލްޑްތަކުގެ `seq` އެއް، ކޮންމެ
އެއްޗެއްގައި `id` އަކާއި `type` އެއް (`s4`، `u1`، `f8`، `str`، ބޭނުންކުރާ ފަރާތުން
ކަނޑައަޅާ ބާވަތެއް، ...)، އަދި `size`، `encoding`، `terminator`، `repeat`
(`eos`، `expr`، `until`)، `if`، ވޭރިއަންޓް ރެކޯޑްތަކަށް `switch-on`، ހިސާބުކުރެވޭ
`instances`، އަދި އެންމެ މަތީ ލެވެލްގައި `endian`. އެ ހަދާފައިވަނީ ކޮންމެ
ބައިނަރީ ފޯމެޓެއް ރިވާސް އިންޖިނިއަރިންގ ކުރުމަށް؛ އާންމު ފޯމެޓް ގެލެރީގައި
(https://formats.kaitai.io) ހަގީގީ ސަތޭކަ ގިނަ ސްޕެސިފިކޭޝަން ހުރި. މި
މޮޑިއުލްގެ ދެ މިސާލަށް `src/main/ksy` ބަލާ: ބައިނަރީ "point" ރެކޯޑަކާއި CSV
ފައިލެއް.

**DFDL އާއި DRB އާ ތަފާތުކޮށް، `.ksy` އެއް ރަންޓައިމްގައި ނުކިޔޭ.** Kaitai Struct
ކޮމްޕައިލަރ (`ksc`) އިން އެ ކުރިން ސޯސް ކޯޑަކަށް ބަދަލުކުރޭ - މިތާގައި، Java
ކްލާހަކަށް - އަދި ބައިޓްތައް ޕާސް ކުރަނީ އެ ކްލާސް. އެހެންވީމާ:

- `KaitaiFormatSpecification` ގައި ނަން ބުނަނީ **ޖެނެރޭޓްކުރި ކްލާހެއްގެ**
  (`new KaitaiFormatSpecification(Point2d.class)`)، `.ksy` ފައިލެއްގެ ނޫން.
- ޖެނެރޭޓްކުރި ކްލާސްތައް އެޕްލިކޭޝަނުގެ ތެރެއަށް ކޮމްޕައިލް ކުރަން ޖެހޭ. މި
  މޮޑިއުލްގެ އެއްޗެހި `src/main/java/.../generated/` ގެ ދަށުގައި ރިޕޮޒިޓަރީގައި
  ހުރި، އެހެންވީމާ އޭގެ ބިލްޑަށް ކޮމްޕައިލަރ ބޭނުމެއް ނުވޭ.
- archive-manager ގެ RepInfo ޓޫލްސްއިން އޭގެ އިންޖީނާ ނުބެހޭ ތަފްސީލުން `.ksy`
  އެއް ޖެނެރޭޓް ކުރޭ (ރެކޯޑަކަށް އަދި އިޚްތިޔާރުގެ ބްރާންޗަކަށް އެއް ބާވަތް،
  `repeat: expr`/`eos`، `if`، `switch-on`، `terminator` އާއެކު ލިޔުމުގެ ފީލްޑް؛
  އަދި ހޮވާފައިވާ ލެންގުއޭޖްތަކުގެ ތެރޭގައި Kaitai ހިމެނޭނަމަ، ބިޓް ފީލްޑް `bN`،
  `size:` ރެކޯޑް، `process: zlib` އަދި ތަނެއްގައިވާ އެލިމެންޓްތަކަށް `pos:` އާއެކު
  `instances`). އެއިން ނަމޫނާ ފައިލަކާ ދެކޮޅަށް އެ ޓެސްޓް **ކުރެވޭ**: އޭގައި
  Kaitai Struct ކޮމްޕައިލަރ ހިމެނޭ، އެ ވަކި Java ޕްރޮސެހެއްގެ ގޮތުގައި ހިންގައި،
  ޖެނެރޭޓްކުރި Java ހަމަ އެ ޕްރޮސެހުގައި ކޮމްޕައިލްކޮށް ލޯޑް ކުރޭ
  (`KaitaiSampleRunner`؛ archive-manager ގެ README ބަލާ).

## Kaitai Struct ބޭނުންކުރާ ކަންކަން

މި ޕްރޮޖެކްޓްގެ ދެ ކުޑަ މިސާލުން ބޭރުން، Kaitai Struct ގިނައިން ބޭނުންކުރަނީ
ކުރިން ހުރި ބައިނަރީ ފޯމެޓްތައް ތަފްސީލުކޮށް ރިވާސް އިންޖިނިއަރިންގ ކުރުމަށް.
ގެލެރީގެ ސްޕެސިފިކޭޝަންތަކުގައި ހިމެނޭ:

- މީޑިއާ ކޮންޓެއިނަރ: MP4، AVI، WAV، MIDI؛
- އެކްޒެކިއުޓަބަލް އަދި އެހެން ބައިނަރީ ފޯމެޓް: ELF، PE/EXE، Mach-O، Java ގެ
  `.class`؛
- ފައިލް ސިސްޓަމް އަދި ފޮރެންސިކްސް: NTFS، ext2، Windows ރަޖިސްޓްރީ ހައިވް،
  ޕްރީފެޗް ފައިލް، އިވެންޓް ލޮގް (މެލްވެއަރ ތަހުލީލާއި CTF ގެ ގޮންޖެހުންތަކުގައި
  މަޝްހޫރު)؛
- އާކައިވް އަދި ކޮމްޕްރެޝަން ފޯމެޓް، ގޭމް އެސެޓް ފޯމެޓް، އަދި ނެޓްވޯކް
  ޕްރޮޓޮކޯލާއި ޕެކެޓް ކެޕްޗަރ ފޯމެޓް (PCAP).

ގެލެރީގެ ކޮންމެ `.ksy` އެއް، މިތާގެ މިސާލުތަކާ އެއްގޮތަށް، މި އެޑަޕްޓަރާއެކު
ކޮމްޕައިލްކޮށް ބޭނުންކުރެވޭނެ.

  ޕާސަރުތަކާއި ޑޮކިއުމެންޓޭޝަނާއެކު.

- [Kaitai Struct Web IDE](https://ide.kaitai.io) -- ބްރައުޒަރުގައި ފައިލަކާ ދެކޮޅަށް
  ތަފްސީލެއް ޓެސްޓް ކޮށްލާ.

## ކްލާސްތައް ޖެނެރޭޓް ކުރުން

`.ksy` އެއް އެޑިޓް ކުރުމަށްފަހު، `src/main/ksy` އިން، Kaitai Struct ކޮމްޕައިލަރ
(0.11، https://kaitai.io) އިން އަލުން ޖެނެރޭޓް ކުރޭ:

    kaitai-struct-compiler -t java --java-package info.oais.infomodel.structure.kaitai.generated --debug --outdir ../java point2d.ksy csv_points.ksy

ޖެނެރޭޓްކުރި ކްލާސްތަކުން ކޮންމެ ފީލްޑެއް ކިޔުނު ތަން ރެކޯޑް ކުރަނީ `--debug`
ގެ ސަބަބުން، އެއީ މި އެޑަޕްޓަރުން ބައިޓްގެ ތަންތަނަށް ބަދަލުކުރާ އެއްޗެއް (ތިރީގައި
ބަލާ). އެ ދޫކޮށްލިޔަސް އެހެން ހުރިހާ އެއްޗެއް ހިނގާނެ، ހަމައެކަނި ތަންތަން ނެތި.

## އެޑަޕްޓަރު ހިނގާ ގޮތް

- **އާންމު، ރިފްލެކްޝަނުން.** `KaitaiReflectiveStructureNode` އިން، ފޯމެޓަށް
  ޚާއްޞަ ކޯޑެއް ނެތި، ޖެނެރޭޓްކުރި ކޮންމެ ކްލާހެއް ބަލާ، Kaitai ގެ Java ޓާގެޓްގެ
  ގަވާއިދުތައް ބޭނުންކޮށްގެން: ކޮންމެ ފީލްޑަކީ ފީލްޑްގެ ނަމުގައި camelCase އިން،
  `get` ޕްރިފިކްސެއް ނެތި، އާގިއުމަންޓެއް ނެތް އާންމު އެކްސެސަރެއް (`label_len`
  ވާނީ `labelLen()` އަށް)، ތެރޭގައިވާ ބާވަތަކީ އެހެން `KaitaiStruct` އެއް، އަދި
  `repeat` ފީލްޑަކީ `List` އެއް. Kaitai ގެ އަމިއްލަ ހިސާބު ބަލަހައްޓާ
  އެކްސެސަރުތައް (`_io`، `_parent`، `_root`، `_read`، ...) ދޫކޮށްލެވޭ. ދަރިން
  އަންނަނީ **ފައިލްގެ ތަރުތީބުން**: `--debug` ކްލާހެއްގެ `_seqFields` ލިސްޓުން،
  ނޫންނަމަ ކްލާހުގެ ކަނޑައަޅާފައިވާ ފީލްޑްތަކުގެ ތަރުތީބުން (Java ރިފްލެކްޝަނުން
  މެތަޑްތަކުގެ ތަރުތީބު ޔަގީން ނުކުރޭ).
- **ބާކީ ބައިޓްތައް.** ރޫޓް ނޯޑްގެ `trailingBytes` އެޓްރިބިއުޓުން
  (`StructureNode.TRAILING_BYTES`) ޕާސް ނުކުރެވުނު ބައިޓްގެ ޢަދަދު ބުނޭ (ސްޓްރީމްގެ
  ފަހު ތަން އޭގެ ސައިޒާ އަޅާކިޔާއިރު).
- **ބާވަތާއެކު އަގުތައް.** އަގުތައް އަނބުރާ އަންނަނީ ޖެނެރޭޓްކުރި
  އެކްސެސަރުތަކުގެ Java ބާވަތްތަކުން (`int`، `long`، `double`، `String`،
  `byte[]`، ...).
- **ތަކުރާރަކީ `ARRAY` ނޯޑެއް.** `repeat` ފީލްޑެއް ވާނީ `ARRAY` ބާވަތުގެ އެއް
  ނޯޑަކަށް، އޭގެ ދަރިންގެ ނަންތަކަކީ `0`، `1`، ... (DFDL އާއި DRB އެޑަޕްޓަރުތަކުން
  އޭގެ ބަދަލުގައި ހަމަ އެއް ނަމެއްގެ އެއްބަނޑު އެއްބަފާ ނޯޑްތައް ބޭނުންކުރޭ).
  ތާވަލް ވިއުތަކުން މި ރޯތައް ހޮވަނީ `<rows select="array">` އިން.
- **`--debug` ބިލްޑްތަކުން ބައިޓްގެ ތަންތަން.** `--debug` އާއެކު ކޮމްޕައިލްކުރި
  ކްލާހެއްގައި އާންމު `_attrStart`/`_attrEnd` މެޕްތައް (ކޮންމެ ފީލްޑެއްގެ ފެށޭ
  އަދި ނިމޭ އޮފްސެޓް، އެކްސެސަރުގެ ނަމުން) އަދި `_arrStart`/`_arrEnd` (ތަކުރާރުވާ
  ފީލްޑެއްގެ ކޮންމެ އެލިމެންޓަކަށް އެއް އެންޓްރީ) ހުރި. އެޑަޕްޓަރު އެއްޗެހި ކިޔާ،
  އެހެންކަމުން ކޮންމެ ފީލްޑަކުން - އަދި ތަކުރާރުވާ ފީލްޑެއްގެ ކޮންމެ
  އެލިމެންޓަކުން - އޭގެ ބައިޓް ރޭންޖް ރިޕޯޓް ކުރޭ. `--debug` ކްލާހަކުން އޭގެ
  ކޮންސްޓްރަކްޓަރުގައި ޕާސް ވެސް ނުކުރޭ؛ `KaitaiStructureRepInfo` އިން އެކަން
  ދެނެގަނެ `_read()` އަމިއްލައަށް ކޯލް ކުރޭ (އެފަދަ ކްލާހެއް ސީދާ ހަދާނަމަ
  ތިޔަބޭފުޅާ އެ ކޯލް ކުރޭ).
- **ސްވިޗް ބާވަތްތައް.** `switch-on` ފީލްޑަކަށް، ނޯޑްގެ ބާވަތުގެ ނަމަކީ
  ހަގީގަތުގައި ޕާސްކުރި ބާވަތް، ކަނޑައަޅާފައިވާ އާންމު ބާވަތެއް ނޫން.
- **މެމޮރީގައި.** ޕާސް ކުރުމުގެ ކުރިން ޑިޖިޓަލް އޮބްޖެކްޓް މުޅިން ބައިޓް ބަފަރަކަށް
  ކިޔެވޭ.

## ޑޭޓާ އަނބުރާ ލިޔުން

`KaitaiStructureRepInfo` އަކީ Kaitai Struct ގެ ކިޔައި ލިޔުމުގެ މޯޑުން (`kaitai-struct-compiler -w`،
Java އާއި Python ހަމައެކަނި، 0.11 އިން ފެށިގެން) ކޮމްޕައިލްކުރި ކްލާސްތަކަށް `WritableStructureRepInfo`
އެއް؛ ކިޔުމަށް ހަމައެކަނި ހަދާފައިވާ ކްލާހެއް އެ ބަޔާނާއެކު ބަލައެއް ނުގަނޭ. `write(dataObject, changes)`
އިން ޑޭޓާ ކިޔައި، ފަހުން ކިޔާ އިންސްޓަންސްތައް ނަގައި، ޖެނެރޭޓްކުރި ސެޓަރުތަކުން ބަދަލުކުރި އަގުތައް
ސެޓްކޮށް (ޕާތުގެ ފިޔަވަޅުތަކުން ފީލްޑްތަކަށް ނަން ދެނީ `.ksy` ގައިވާ ގޮތަށް، `sample_count`، ނުވަތަ
އެކްސެސަރުން ދޭ ގޮތަށް، `sampleCount`؛ `[n]` އިން ތަކުރާރުވާ ފީލްޑެއްގެ އެލިމެންޓެއް ހޮވާ)، ބަދަލުކުރި
ކޮންމެ އޮބްޖެކްޓަކުން އަމިއްލައަށް ޗެކް ކުރުވައި (`_check()`، މިސާލަކަށް އޭގެ ލިސްޓާ ދިމާ ނުވާ
ތަކުރާރުގެ ޢަދަދެއް، ނުވަތަ އޭގެ ސައިޒަށް ނުވަދެވޭ ސްޓްރިންގއެއް ބަލައެއް ނުގަނޭ)، ހުރިހާ އެއްޗެއް
`_write` އިން ލިޔޭ. Kaitai ލިޔަނީ ސާބިތު ސައިޒެއްގެ ސްޓްރީމަކަށް، އަދި ޑޭޓާގެ ނިމުމާ ހަމައަށް ތަކުރާރުވާ
ނުވަތަ ސައިޒުކުރާ އެލިމެންޓެއް ނިމެން ޖެހެނީ ހަމަ ސްޓްރީމް ނިމޭ ތަނުގައި، އެހެންވީމާ ލިޔާ ފަރާތް ފަށަނީ
ޑޭޓާގެ އަމިއްލަ ސައިޒުން، އަދި Kaitai ރިޕޯޓް ކުރާ ގޮތަށް އެ ބަދަލުކުރޭ. ކަނޑައަޅާފައިވާ `size` އެއްގެ
ބާވަތެއްގެ ތެރޭގައި ބޭނުން ނުކުރާ ބައިޓްތައް ލިޔެވެނީ ސުމެއްގެ ގޮތުގައި.

## އެނގިފައިވާ ހަދުތައް

- ރަންޓައިމްގައި ތަފްސީލުތައް ލޯޑް ނުކުރެވޭ: ކޮންމެ ފޯމެޓަކަށް ފުރަތަމަ އޭގެ ކްލާސް
  ޖެނެރޭޓްކޮށް ކޮމްޕައިލް ކުރަން ޖެހޭ (archive-manager އިން އޭގެ ނަމޫނާ ޓެސްޓަށް
  ދެކަމެއް ވެސް ބޭނުންވާ ވަގުތު ކުރޭ، ސިކުންތު ކިހާވަރެއް ނަގާ).
- Java ގެ ރިޒާވްޑް ބަސްތަކަކަށްވާ ނަންތަކުގެ ފީލްޑްތައް (`class`، `int`، `null`، ...)
  Kaitai Struct ކޮމްޕައިލަރުން ނަން ބަދަލު ނުކުރާތީ، އެއްޗެހީގެ Java ކޮމްޕައިލް
  ނުވޭ؛ Kaitai ޓާގެޓަކަށް ވާއިރު archive-manager ގެ އެޑިޓަރުން އެފަދަ ނަންތައް
  ބަލައެއް ނުގަނޭ. YAML އިން ބޫލިއަން ނުވަތަ null ގެ ގޮތުގައި ކިޔާ ނަންތައް (`on`،
  `no`، `null`) `.ksy` އެއްގައި ކޯޓް ކުރަން ޖެހޭ، archive-manager ގެ ޖެނެރޭޓަރުން
  ކުރާ ފަދައިން.
- ޕާސް ކުރުމަކީ ވަގުތުން މެމޮރީގައި ކުރާ އެއްޗެއް؛ ވަރަށް ބޮޑު ފައިލްތަކަށް
  `KaitaiStructureRepInfo` ގެ `RandomAccessFileKaitaiStream` ވޭރިއަންޓެއް އަކީ
  ތަބީޢީ ފުޅާކުރުމެއް.
