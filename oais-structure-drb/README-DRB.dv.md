# oais-structure-drb ގެ ނޯޓުތައް

މި މޮޑިއުލުން GAEL Consultant ގެ Java **DRB** ("Data Request Broker"،
`fr.gael.drb`) އާންމު `StructureNode` މޮޑެލާ ގުޅުވަނީ، `oais-structure-dfdl` އިން
Apache Daffodil އަށް ކުރާ ފަދައިން. އެ ލިޔެ ޓެސްޓް ކޮށްފައިވަނީ **DRB 2.5.13** އާ
ދެކޮޅަށް، އެއީ GNU LGPL v3 ލައިސަންސްގެ ދަށުން، މި ރިޕޮޒިޓަރީގެ އަމިއްލަ
`third-party/maven-repo` އިން ދެވޭ އެއްޗެއް (DRB އަކީ Maven Central ގައި ހުރި
އެއްޗެއް ނޫން) - ލައިސަންސް، ސޯސް jar، އަދި DRB ގެ އަމިއްލަ ޑިޕެންޑެންސީތަކުގެ
ތެރެއިން ބޭނުންކުރާ އަދި ނުކުރާ އެއްޗެހި ބެލުމަށް `third-party/README.md` ބަލާ.

## DRB ބޭނުންކުރާ ކަންކަން

DRB ތަރައްގީ ކުރީ GAEL Systems އިން ESA އަށް ފެޑެރޭޓެޑް "ވާޗުއަލް ފައިލް
ސިސްޓަމެއް" ގެ ގޮތުގައި: ތަފާތު ބާވަތްތަކުގެ ބިމުގެ މުރާޤަބާ (Earth Observation)
ޑޭޓާ ޕްރޮޑަކްޓްތަކުގެ މައްޗަށް ބެލޭނެ އެއް ޓްރީއެއް، Sentinel ގެ ގްރައުންޑް
ސެގްމަންޓް ޓޫލްތަކުގައި ބޭނުންކުރާ. އާންމުކޮށް އެ ބޭނުންކުރަނީ:

- އެތައް ފައިލެއް ގުޅުވާ ސެޓެލައިޓް ޕްރޮޑަކްޓް ކޮންޓެއިނަރުތަކަށް (SAFE ފޯމެޓް)؛
- netCDF، HDF5، JPEG2000 ސެޓެލައިޓް ފޮޓޯ، DIMAP، GeoTIFF؛
- XML މެޓަޑޭޓާ، އަދި މަތީގެ ކޮންމެ އެއްޗެއް އޮޅާލާ ZIP/TAR އާކައިވްތައް.

މި މޮޑިއުލުން ބޭނުންކުރަނީ DRB 2.5.13 ގެ SDF ސްކީމާތަކާއި އޭގައި ހިމެނޭ XML
ސަޕޯޓް؛ މަތީގެ ގިނަ ޕްރޮޑަކްޓްތަކުގެ ފޯމެޓް އިމްޕްލިމެންޓޭޝަންތަކަކީ ވަކި DRB
ޕެކޭޖްތަކެއް، އަދި އެއްޗެހި މިތާގައި ނުހިމެނޭ. މި ޕްރޮޖެކްޓްގެ މިސާލުތައް (ބައިނަރީ
"point" ރެކޯޑަކާއި CSV ތާވަލެއް، DFDL އާއި Kaitai މޮޑިއުލްތަކުގައިވާ ހަމަ އެ
އެއްޗެހި) ހުރީ `src/test/resources` ގައި.

## މިސާލުތަކުގެ ގެލެރީތައް

މިތާގައި ބޭނުންކުރާ Java DRB އަށް DRB SDF ސްކީމާތަކުގެ އާންމު ގެލެރީއެއް ނެތް؛
މި ޕްރޮޖެކްޓްގެ އެއްޗެހި ހުރީ `src/test/resources` ގައި. GAEL ގެ Python
ވަރޝަން، drb-python އަށް، ފޯމެޓް ސަޕޯޓް ލިބެނީ ޑްރައިވަރ ޕެކޭޖްތަކުން:

- [GitLab ގައި drb-python](https://gitlab.com/drb-python) -- ޑްރައިވަރުތައް
  (މިސާލަކަށް XML، ZIP، TAR، netCDF)، ޕްރޮޑަކްޓްތައް ދެނެގަންނަ ޓޮޕިކްތައް
  (މިސާލަކަށް Sentinel SAFE) އަދި އެޑް-އޮންތައް، ސޯސްގެ ގޮތުގައި.
- [PyPI ގައި drb-python ޑްރައިވަރުތައް](https://pypi.org/search/?q=drb-driver) --
  ހަމަ އެ ޑްރައިވަރުތައް އިންސްޓޯލް ކުރެވޭ ޕެކޭޖްތަކެއްގެ ގޮތުގައި.

## ޑިޖިޓަލް އޮބްޖެކްޓެއް ތަފްސީރުކުރާނެ ދެ ގޮތް

`DrbFormatSpecification` އިން އެކެއް ހޮވާ:

- **SDF ސްކީމާއެއް** - `new DrbFormatSpecification(schemaUri)`. DRB ގެ ޑިކްލަރޭޓިވް
  ޑިސްކްރިޕްޝަން ލެންގުއޭޖް، DFDL ސްކީމާއެއްގެ ބަދަލު: އޭގެ އެލިމެންޓްތަކުގައި
  `http://www.gael.fr/2004/12/drb/sdf` ނޭމްސްޕޭސްގެ `sdf:block` އެނޮޓޭޝަންތައް
  ހުންނަ އާދައިގެ XML Schema އެއް - `sdf:length`، `sdf:byteOrder` (`MSB`/`LSB`)،
  `sdf:encoding` (`BINARY`/`ASCII`/`EBCDIC`)، `sdf:occurrence`، `sdf:delimiter`،
  `sdf:offset`، ... ބައިނަރީ ރެކޯޑް، ސާބިތު ފުޅާމިނުގެ ލިޔުން އަދި ވަކިކޮށްފައިވާ
  ލިޔުން (މިސާލަކަށް CSV، ކޮންމެ ފީލްޑެއްގައި `sdf:delimiter` އެއް ހުންނަ)
  މިގޮތަށް ތަފްސީލު ކުރެވޭ. little-endian ބައިނަރީ ރެކޯޑަކާއި CSV މިސާލަކަށް
  `src/test/resources` ބަލާ؛ archive-manager ގެ RepInfo ޓޫލްސްއިން ވެސް އޭގެ
  އިންޖީނާ ނުބެހޭ ތަފްސީލުން މި ސްކީމާތައް ޖެނެރޭޓް ކުރޭ (ޢަދަދުތަކާއި
  ޝަރުތުތައް `sdf:occurrence` ކުއެރީތަކެއްގެ ގޮތުގައި، އިޚްތިޔާރުތައް
  `sdf:signature` ކުއެރީތަކެއްގެ ގޮތުގައި، CSV ރެކޯޑްތައް `sdf:delimiter` އާއެކު).
- **DRB ގެ އަމިއްލަ ފޯމެޓް ދެނެގަތުން** -
  `DrbFormatSpecification.autoDetect("xml")`. DRB އިން އޭގެ ހިމެނޭ
  އިމްޕްލިމެންޓޭޝަންތަކުގެ ތެރެއިން އެކެއް (XML، ...) ހޮވަނީ **ފައިލް
  އެކްސްޓެންޝަނުން**، އެހެންވީމާ ޑިޖިޓަލް އޮބްޖެކްޓްގެ އާދައިގެ އެކްސްޓެންޝަން
  ދޭން ޖެހޭ.

## އެޑަޕްޓަރު ހިނގާ ގޮތް

- **ރިފްލެކްޝަން، ކޮމްޕައިލް ވަގުތުގެ ޑިޕެންޑެންސީއެއް ނޫން.** DRB އަށް އަތްލާ
  ހަމައެކަނި ކްލާހަކީ `DrbApi`، އޭގެ އާންމު އިންޓަފޭސްތަކުގެ ތެރެއިން (`DrbNode`،
  `DrbFactoryImpl`، `DrbAttribute`، ...). މޮޑިއުލް DRB ނެތި ކޮމްޕައިލް ވޭ، އަދި
  DRB ކްލާސްޕާތުގައި ނެތްނަމަ `DrbStructureInterpreterProvider.isAvailable()`
  ސާދާކޮށް `false` ރިޕޯޓް ކުރޭ؛ އެޕްލިކޭޝަންތަކުން ރަންޓައިމްގައި
  `fr.gael.drb:drb` (އަދި އޭގެ log4j 1.x ލޮގިންގ ކޯލްތަކަށް
  `org.slf4j:log4j-over-slf4j`) އިތުރުކުރޭ. މި މޮޑިއުލްގެ ޓެސްޓްތަކުގައި ހަގީގީ
  DRB ބޭނުންކުރޭ.
- **އެހެން އެޑަޕްޓަރުތަކެއް ފަދައިން، މުޅިން މެމޮރީގައި.** DRB އިން ޑޭޓާ ހުޅުވަނީ
  ޕާތުން، އެހެންވީމާ ބައިޓްތައް ވަގުތީ ފައިލަކަށް ލިޔެވޭ؛ DRB ހަދާ ނޯޑް ޓްރީ ސާދާ
  `StructureNode` ތަކަށް ކޮޕީ ކުރެވޭ (`DrbApi.MAX_NODES` އިން ހަދުކޮށްފައި)، DRB
  ގެ ނޯޑްތައް ބަންދުކުރެވޭ، އަދި `apply` އަނބުރާ ދިއުމުގެ ކުރިން ފައިލް
  ފޮހެލެވޭ.
- **ބާވަތާއެކު އަގުތައް.** ކޮންމެ ނޯޑެއްގެ ކަނޑައަޅާފައިވާ XML Schema ބާވަތަށް
  ބަލައި، ނަންބަރުތައް އަނބުރާ އަންނަނީ `Long` (އޭގެ ރޭންޖުން ބޭރުގައި
  `BigInteger`) ނުވަތަ `Double` އެއްގެ ގޮތުގައި، ލިޔުން `String` އެއްގެ ގޮތުގައި.
- **ބައިޓްގެ ތަންތަނާއި ޑޮކިއުމެންޓޭޝަން.** DRB އިން ޑިކޯޑްކުރި ކޮންމެ ނޯޑެއްގެ
  ބައިޓް `offset` އާއި `length` ރިޕޯޓް ކުރޭ، އެއީ `getSourceRange()` އަށް ވާނެ،
  އަދި އެލިމެންޓެއްގެ `xs:documentation`، `documentation` އެޓްރިބިއުޓެއްގެ
  ގޮތުގައި.
- **ކުރު ޑޭޓާއަކީ މައްސަލައެއް.** ސްކީމާއިން ތަފްސީލުކުރާ ވަރަށްވުރެ ކުރު
  ޑޭޓާއަކުން DRB އަމިއްލައަށް ނާކާމިޔާބެއް ނުވޭ (ނިމުމުން ބޭރުގެ ތަންތަން ރިޕޯޓް
  ކުރޭ)؛ އެޑަޕްޓަރު ކޮންމެ ނޯޑެއްގެ ތަން ޑޭޓާގެ ސައިޒާ އަޅާކިޔައި، އޭގެ ބަދަލުގައި
  `StructureInterpretationException` ދިމާކޮށްދޭ.
- **ބާކީ ބައިޓްތައް.** ރޫޓް ނޯޑްގެ `trailingBytes` އެޓްރިބިއުޓުން
  (`StructureNode.TRAILING_BYTES`) ސްކީމާއިން ތަފްސީލުކުރާ އެއްޗެއްގެ ނިމުމަށްފަހު
  ހުރި ބައިޓްގެ ޢަދަދު ބުނޭ، އެހެންކަމުން ކުރިން ހުއްޓޭ ތަފްސީލެއް ފެނޭ.
- **ސީރިއަލައިޒް ކޮށްފައި.** DRB އިން ތްރެޑް ސޭފްޓީގެ އެއްވެސް ޔަގީންކަމެއް
  ނުދޭތީ، އެއަށް ކުރާ ކޯލްތަކުން އެއް ލޮކް ހިއްސާ ކުރޭ.

## DRB ބަލައިގަންނާނެ SDF ސްކީމާތައް ލިޔުން

މިކަންކަން ފާހަގަވީ archive-manager ގެ ތަފްސީލުތަކުން ސްކީމާތައް ޖެނެރޭޓް
ކުރަމުން ދިޔައިރު:

- **ޑޭޓާއަށް ބިނާވާ ކުއެރީއަކަށް `constant="false"` ފާހަގަ ކުރޭ**
  (`<sdf:occurrence constant="false">../count</sdf:occurrence>`). ނޫންނަމަ DRB އެ
  އެއް ފަހަރު ހިސާބުކޮށް، ކޮންމެ ތަކުރާރަކަށް ފުރަތަމަ ޖަވާބު އަލުން ބޭނުންކުރޭ.
- **އިޚްތިޔާރަކީ `sdf:signature` ކުއެރީތަކާއެކު އެތައް އިޚްތިޔާރީ އެލިމެންޓެއް**
  (މިސާލަކަށް `../kind = 2`)؛ DRB އިން ކިޔަނީ ސިގްނޭޗަރު ތެދުވާ އެއްޗެއް.
  ބްރާންޗެއްގެ ތެރޭގައިވާ ކުއެރީތައް ހުންނަނީ ފެންނަ ވަރަށްވުރެ އެއް ލެވެލް
  ފުނުގައި، އެއްޗެހި ހިސާބުކުރަނީ ބްރާންޗްގެ އަމިއްލަ ނޯޑުން ކަމުން.
- **ޑިލިމިޓަރަކީ އެއް ކެރެކްޓަރ.** `sdf:delimiter` ގައި "ނުވަތަ ޑޭޓާގެ ނިމުން"
  ބަދަލެއް ނެތް.
- **ކުއެރީތަކުން Java ކޯލް ކުރެވޭ.** DRB ގެ XQuery އިން `java:` ނޭމްސްޕޭހެއްގެ
  ތެރެއިން (`declare namespace s = "java:java.lang.System"`) ކޮންމެ އާންމު
  ސްޓެޓިކް Java މެތަޑެއް ކޯލް ކުރޭ، އަދި `doc()` އިން ފައިލްތަކާއި URL ކިޔާ.
  ބޭނުންކުރާނީ އިތުބާރު ކުރެވޭ SDF ސްކީމާތައް ހަމައެކަނި؛ މިއިން އެއްވެސް
  އެއްޗެއް ކުރާ، އަތުން ލިޔުނު ސްކީމާތައް ހިންގުމުގެ ކުރިން archive-manager ދެކޮޅު
  ހަދާ.

## ޑޭޓާ އަނބުރާ ލިޔުން

SDF ސްކީމާއެއް ހުރިއިރު `DrbStructureRepInfo` އަކީ `WritableStructureRepInfo` އެއް: DRB ގެ SDF
ބްލޮކްތަކުން `setValue` ސަޕޯޓް ކުރޭ، އެއިން އަގެއް ކިޔުނު ތަނަށް، ޑޭޓާގެ ކޮޕީއަކަށް، އަނބުރާ ލިޔޭ
(ވަގުތީ ފައިލަށް ލިޔެވޭތީ، DRB އެ ހުޅުވަނީ ކިޔައި ލިޔޭ ގޮތަށް). `write(dataObject, changes)` އިން
*ކޮންމެ* އަގެއް އަލުން ލިޔޭ - އޭގެ އައު އަގު، ނުވަތަ އަދި ކިޔުނު އަގު - އެހެންކަމުން ބަދަލެއް ނެތި
އަނބުރާ ލިޔުމުން (`roundTrip(dataObject)`) DRB އިން ކޮންމެ އަގެއް ރައްކާކޮށްފައިވާ ގޮތަށް އެންކޯޑް
ކުރޭތޯ ޓެސްޓް ކުރޭ. ސްކީމާއިން ތަފްސީލު ނުކުރާ ބައިޓްތައް ހުރި ގޮތަށް ބާކީ ހުރުމުން، މިތާގައި
އެއްގޮތް ދިއުމާއި އައުމަކުން ސްކީމާއިން ކޮންމެ ބައިޓެއް ހިމަނާކަން ނުދައްކާ (އެކަމަށް ޑިކޯޑިންގއިން ބާކީ
ބައިޓްތައް ރިޕޯޓް ކުރޭ). ވަކިކޮށްފައިވާ އަގެއްގެ ދިގުމިން ބަދަލުވެދާނެ - ފަހުން އަންނަ އެއްޗެއް DRB
ހިއްލާލާ - ނަމަވެސް ސާބިތު ދިގުމިނެއްގެ އަގެއްގެ ނުވާނެ: DRB އިން ކުރު ލިޔުމެއްގެ އަގެއް ފުރާލައި،
ދިގު އެއްޗެއް ކަނޑާލަނީ ޝަކުވާއެއް ނުކޮށް، އެހެންވީމާ އެޑަޕްޓަރު ލިޔުނު ޑޭޓާ އަލުން ކިޔައި، އެދުނު
ގޮތަށް ނުނިކުމެ ބަދަލެއް ބަލައެއް ނުގަނޭ.

ސްކީމާއިން `LSB` ބުނިޔަސް، DRB 2.5.13 އިން 4 ބައިޓްގެ float އެއް ލިޔަނީ big-endian ގޮތަށް
(އިންޓީޖަރާއި double ބަދަލުކުރޭ، ނަމަވެސް float ނޫން)؛ އެޑަޕްޓަރު ރައްކާކުރި ބައިޓްތައް little-endian
ގޮތަށް ކިޔެވޭ ކޮންމެ float އެއް ފާހަގަކޮށް، DRB ނިމުމުން، އެ އަމިއްލައަށް little-endian ގޮތަށް ލިޔޭ.

- `xs:hexBinary`/`xs:base64Binary` ޑިކޯޑް ވަނީ އެއްވެސް އެއްޗަކަށް ނޫން؛ ރޯ
  ބައިޓްތައް ތަފްސީލުކުރާނީ ތަކުރާރުވާ `xs:unsignedByte` އެއްގެ ގޮތުގައި

  އަދި drb-python ހުރިހާ އެއްޗަކުން އެ ކިޔާ.)
