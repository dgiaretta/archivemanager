# oais-structure-dfdl ގެ ނޯޓުތައް

މި މޮޑިއުލުން **DFDL** - Open Grid Forum ގެ Data Format Description Language
(GFD.207) - އާންމު `StructureNode` މޮޑެލާ ގުޅުވަނީ، DFDL ގެ ރިފަރެންސް
އިމްޕްލިމެންޓޭޝަން، **Apache Daffodil 3.11.0** (`daffodil-japi_2.13`، Apache
License 2.0، Maven Central އިން) ބޭނުންކޮށްގެން.

## ފޯމެޓެއް ތަފްސީލުކުރާ ގޮތް

DFDL ސްކީމާއަކީ އާދައިގެ XML Schema އެއް، އޭގެ އެލިމެންޓްތަކުގައި ކޮންމެ އެއްޗެއް
ޑޭޓާގައި ހުންނަ ގޮތް ބުނާ `dfdl:` އެނޮޓޭޝަންތައް ހުންނާނެ: `dfdl:length` އާއި
`dfdl:lengthKind`، `dfdl:byteOrder`، `dfdl:representation` (`binary`/`text`)،
`dfdl:encoding`، ވަކިކޮށްފައިވާ ލިޔުމަށް `dfdl:separator`/`dfdl:terminator`،
ތަކުރާރަށް `dfdl:occursCount`، އަދި ފީލްޑެއްގެ ދިގުމިން އަނެއް ފީލްޑަކުން ނަގާ
`dfdl:length="{ xs:int(../tns:labelLen) }"` ފަދަ އެކްސްޕްރެޝަންތައް. ބައިނަރީ
ރެކޯޑް، ސާބިތު ފުޅާމިނުގެ ލިޔުން އަދި ވަކިކޮށްފައިވާ ލިޔުން (މިސާލަކަށް CSV)
ހުރިހާ އެއްޗެއް ތަފްސީލު ކުރެވޭ. ބައިނަރީ "point" ރެކޯޑަކާއި CSV މިސާލަކަށް
`src/test/resources` ބަލާ، އަދި އިތުރަށް `oais-structure-demo`؛ archive-manager
ގެ RepInfo ޓޫލްސްއިން ވެސް އޭގެ އިންޖީނާ ނުބެހޭ ތަފްސީލުން DFDL ސްކީމާތައް
ޖެނެރޭޓް ކުރޭ (ޢަދަދުތައް `dfdl:occursCount` ގެ ގޮތުގައި، ޝަރުތުތަކާއި
އިޚްތިޔާރުތައް `dfdl:choiceDispatchKey`/`dfdl:choiceBranchKey` އާއި ފެންނަ
ފަހަރުގެ އެކްސްޕްރެޝަންތަކެއްގެ ގޮތުގައި، CSV ރެކޯޑްތައް
`dfdl:separator`/`dfdl:terminator` އާއެކު؛ އަދި، ހޮވާފައިވާ ލެންގުއޭޖްތަކުގެ
ތެރޭގައި DFDL ހިމެނޭނަމަ، `dfdl:lengthUnits="bits"` އާއެކު ބިޓް ފީލްޑް، ސާފު
ދިގުމިނެއްގެ ރެކޯޑް، `nillable`/`dfdl:nilValue` އާއެކު nil އަގު، އެސްކޭޕް
ބްލޮކެއް `dfdl:defineEscapeScheme` އާއެކު ކޯޓްކުރި CSV އަގު، އަދި
`dfdl:textNumberPattern` ނަންބަރު ފޯމެޓް).

`new DfdlFormatSpecification(schemaUri)` އިން އެޑަޕްޓަރަށް ސްކީމާ ދައްކާ؛ ޕާސް
ކުރެވެނީ ސްކީމާގެ ޑިފޯލްޓް ރޫޓް އެލިމެންޓް.

## DFDL ބޭނުންކުރާ ކަންކަން

މި ޕްރޮޖެކްޓްގެ މިސާލުތައް ގަސްދުގައި ކުޑަ (ބައިނަރީ "point" ރެކޯޑަކާއި CSV
ތާވަލެއް، DFDL، Kaitai އަދި DRB މޮޑިއުލްތަކުގައި އެއްގޮތަށް ބަހައްޓާފައި، އެއްޗެހީގެ
ނަތީޖާ އަޅާކިޔޭނެ ގޮތަށް). DFDL އަމިއްލައަށް ބޭނުންކުރަނީ މާ ގިނަ ކަންކަމަށް. އެ
ހެދީ XML އާއި JSON ގެ ކުރީގެ ލިޔުމާއި ބައިނަރީ *ރެކޯޑް* ފޯމެޓްތަކަށް، މިސާލަކަށް:

- މާލީ މެސެޖިންގ: SWIFT MT، ISO 20022، FIX؛
- މެއިންފްރޭމްގެ ޤަދީމީ ޑޭޓާ: COBOL ކޮޕީބުކްތަކުން ތަފްސީލުކުރާ ސާބިތު
  ފުޅާމިނުގެ އަދި EBCDIC ފައިލްތައް؛
- ސިއްހީ: HL7 v2 (ވަރޓިކަލް ބާރުން ވަކިކޮށްފައިވާ މެސެޖް)؛
- ދިފާއީ އަދި ސަރުކާރު: ސިފައިންގެ މެސެޖް ފޯމެޓް (USMTF، VMF) އަދި EDI (X12)؛
- ސައިންޓިފިކް ޑޭޓާ އަދި ޓެލެމެޓްރީ: NASA/JPL އިން ސްޕޭސްކްރާފްޓް
  އިންސްޓްރޫމަންޓްގެ ޓެލެމެޓްރީއަށް DFDL ބޭނުންކޮށްފައި، ސްޓޭންޑަޑްގެ ސިފަ
  ކަނޑައެޅުނު ބޭނުންތަކުގެ ތެރެއިން އެކެއް.

މި ލިސްޓަކީ ފެށުމެއް، ފުރިހަމަ ލިސްޓެއް ނޫން. GitHub ގައިވާ DFDL Schemas
ޕްރޮޖެކްޓުން މިއިން ގިނަ ފޯމެޓްތަކަށް ހުޅުވާލެވިފައިވާ DFDL ސްކީމާތައް ޝާއިޢު
ކުރޭ (ތިރީގައި ބަލާ).

## މިސާލުތަކުގެ ގެލެރީތައް

- [DFDL Schemas](https://github.com/DFDLSchemas) -- GitHub ގައި ހުޅުވާލެވިފައިވާ
  DFDL ސްކީމާތަކުގެ ކޮމިއުނިޓީ ކަލެކްޝަން، ފޯމެޓަކަށް އެއް ރިޕޮޒިޓަރީ (މިސާލަކަށް
  PCAP، PNG، NITF، EDIFACT، ISO 8583)، ކޮންމެ އެއްޗެއް ޓެސްޓް ޑޭޓާއާއެކު.
- [Apache Daffodil ގެ މިސާލުތައް](https://daffodil.apache.org/examples/) --
  Daffodil ޕްރޮޖެކްޓުގެ ކުޑަ، ހައްލުކޮށްފައިވާ މިސާލުތައް.

## އެޑަޕްޓަރު ހިނގާ ގޮތް

- **އެއް ފަހަރު ކޮމްޕައިލްކޮށް، ދެން އަލުން ބޭނުންކުރޭ.** Daffodil ސްކީމާ
  ކޮމްޕައިލް ކުރަނީ ފުރަތަމަ `apply` ގައި، އަދި ކޮމްޕައިލްކުރި ޕްރޮސެސަރު އެ
  `DfdlStructureRepInfo` އިންސްޓަންސްގައި ކޭޝް ކުރެވޭ - ކޮމްޕައިލް ކުރުމަކީ ކުލި
  ބޮޑު ބައި، ޕާސް ކުރުން ނިސްބަތުން ކުލި ކުޑަ. ސްކީމާއަކަށް އެއް އިންސްޓަންސް
  ހަދައި އެ އަލުން ބޭނުންކުރޭ.
- **ޕާސްކުރި ޓްރީއަކީ Daffodil ގެ އަމިއްލަ އެއްޗެއް.** ނަތީޖާ ލިބެނީ Daffodil
  ގެ W3C DOM އިންފޮސެޓުން، އަދި އެލިމެންޓަށް އެލިމެންޓް އޮޅާލެވޭ
  (`DomStructureNode`)، ކޮޕީއެއް ނުކުރެވޭ. ޑިޖިޓަލް އޮބްޖެކްޓްގެ ބައިޓްތައް
  މުޅިން މެމޮރީއަށް ކިޔެނީ، އެޑަޕްޓަރު އެއްޗެހި ދެ ފަހަރު ޕާސް ކުރާތީ (ދެން
  އަންނަ ނުކުތާ ބަލާ).
- **ބާވަތާއެކު އަގުތައް.** `PositionTrackingInfosetOutputter` އާއެކު ދެވަނަ
  ޕާސަކުން ކޮންމެ ސާދާ އެލިމެންޓެއްގެ ބާވަތާއެކު އަގު ލިބޭ، އެހެންކަމުން
  `xs:int` އެލިމެންޓެއް އަނބުރާ އަންނަނީ `Integer` އެއްގެ ގޮތުގައި،
  `xs:unsignedByte` އަކީ `Short` އެއް، ފަދައިން، DOM ލިޔުމެއްގެ ގޮތުގައި ނޫން.
  Daffodil 3.11 އިން ޔަގީންކޮށްފައި.
- **Daffodil 3.11 ގައި ބައިޓްގެ ތަންތަނެއް ނެތް.** ހަމަ އެ ދެވަނަ ޕާސުން،
  ރިފްލެކްޝަނުން، Daffodil ގެ ކުރީގެ އަދި ފަހުގެ ވަރޝަންތަކުގައި ހުރި ތަން
  ދައްކާ އެކްސެސަރުތައް ވެސް ބަލާ؛ 3.11 ގައި އެއްވެސް އެއްޗެއް ނެތީމާ،
  `getSourceRange()` އަބަދުވެސް ހުސް. (DRB އާއި Kaitai އެޑަޕްޓަރުތަކުން ތަންތަން
  ރިޕޯޓް ކުރޭ.)
- **ތަކުރާރަކީ ހަމަ އެއް ނަމެއްގެ އެއްބަނޑު އެއްބަފާ ނޯޑްތައް.** ތަކުރާރުވާ
  އެލިމެންޓެއް (މިސާލަކަށް CSV `row` އެއް) ފެންނަނީ އޭގެ ބެލެނިވެރިޔާގެ ހަމަ އެއް
  ނަމެއްގެ އެތައް ދަރިންގެ ގޮތުގައި، DRB އެޑަޕްޓަރާއި ސާދާ XML ގެ ހަމަ އެ
  ގަވާއިދު؛ `childrenNamed("row")` ބޭނުންކުރޭ. Kaitai ގެ އެޑަޕްޓަރު ބޭނުންކުރަނީ
  އެއް `ARRAY` ނޯޑެއް.
- **ބާކީ ބައިޓްތައް ރިޕޯޓް ކުރެވޭ، ދޫކޮށެއް ނުލެވޭ.** ސްކީމާގެ ރޫޓް އެލިމެންޓް
  ފުރިހަމަވުމުން Daffodil މަސައްކަތް ހުއްޓާލައި، ފަހުން އަންނަ ޑޭޓާއާ ބެހޭ
  އެއްވެސް އެއްޗެއް ނުބުނޭ. އެޑަޕްޓަރު Daffodil ގެ ފަހު ތަން ނަގައި، ރޫޓް ނޯޑްގެ
  `trailingBytes` އެޓްރިބިއުޓް (`StructureNode.TRAILING_BYTES`) ބާކީ ބައިޓްގެ
  ޢަދަދަށް ސެޓް ކުރޭ.
- **މައްސަލަތަކުގައި Daffodil ގެ އަމިއްލަ ޑައިގްނޯސްޓިކްސް ހުންނާނެ.** ކޮމްޕައިލް
  ނުވާ ސްކީމާއަކުން، ނުވަތަ އެއާ ދިމާނުވާ ޑޭޓާއަކުން
  `StructureInterpretationException` ދިމާވާނެ، އޭގެ މެސެޖުގައި Daffodil ގެ
  ޑައިގްނޯސްޓިކްސް ލިސްޓްކޮށްފައި.
- **ލޮގިންގ.** Daffodil ގެ ލޮގިންގއަށް މޮޑިއުލް ރަންޓައިމްގައި `slf4j-simple`
  ގެނެސްދޭ؛ އަމިއްލަ SLF4J ބައިންޑިންގއެއް ހުރި އެޕްލިކޭޝަނަކުން (archive-manager
  ބޭނުންކުރަނީ Logback) އެ ދޫކޮށްލަންވާނެ.

## Daffodil ބަލައިގަންނާނެ ސްކީމާތައް ލިޔުން

މި ހުރިހާ ކަމެއް ފާހަގަވީ މި ޕްރޮޖެކްޓްގެ ސްކީމާތައް ހަގީގީ Daffodil އިން ކޮމްޕައިލް
ކުރުވަމުން ދިޔައިރު:

- **Daffodil ގެ `GeneralFormat` ހިމަނާ.** ބައެއް ދަށު ލެވެލްގެ ޕްރޮޕަޓީތަކަށް
  (`leadingSkip`، `initiatedContent`، `textBidi`، `floating`، ...) ޑިފޯލްޓެއް ނެތް،
  އަދި އެއްވެސް އެއްޗެއް ސެޓް ނުކޮށް ހުރި ސްކީމާއެއް ކޮމްޕައިލް ކުރުމަށް Daffodil
  ދެކޮޅު ހަދާ.
  `<xs:include schemaLocation="/org/apache/daffodil/xsd/DFDLGeneralFormat.dfdl.xsd"/>`
  (Daffodil ގެ އަމިއްލަ jar އިން ހޯދޭ) އިން ހުރިހާ އެއްޗެއް ސެޓް ކުރޭ؛ ތިޔަބޭފުޅާގެ
  އަމިއްލަ `dfdl:defineFormat`/`dfdl:format` އިން އެއަށް ރިފަރ ކޮށް، ތަފާތު
  އެއްޗެހި ހަމައެކަނި ބަދަލުކުރޭ، މިސާލަކަށް `representation="binary"`.
- **`xs:appinfo` ގެ ސޯހަކީ `http://www.ogf.org/dfdl/`**، `.../dfdl-1.0/` ނޫން
  (ފަހުގެ އެއްޗަކަށް Daffodil އިންޒާރު ދޭ).
- **ފޯމެޓްގެ ޑިފޯލްޓަކީ `explicit` ނަމަ، ރޫޓް އެލިމެންޓަށް
  `dfdl:lengthKind="implicit"` ދޭ**: ކޮމްޕޮޒިޓް އެލިމެންޓެއްގެ ދިގުމިނަކީ އޭގެ
  ދަރިންގެ ޖުމްލަ، އަދި `dfdl:length` ނެތި "explicit" ކޮމްޕައިލް ނުވޭ.
- **ސްކީމާއިން `elementFormDefault="qualified"` ބޭނުންކުރާނަމަ، އެކްސްޕްރެޝަންތަކުގައި
  އެލިމެންޓްގެ ނަންތައް ފުރިހަމަކޮށް ލިޔޭ** (`../tns:labelLen`، `../labelLen` ނޫން).
- **ކޮންމެ CSV ރޯއެއް `dfdl:terminator="%NL; %ES;"` އިން ނިންމާ** (ނިއުލައިނެއް،
  ނުވަތަ ޑޭޓާގެ ނިމުން). ސާދާ `%NL;` ޓާމިނޭޓަރަކުން، ފަހު ލައިނުގައި ނިއުލައިނެއް
  ނެތް ފައިލަކުން އެ ލައިން ގެއްލޭ -- ސިއްރުން، ޕާސް ނުކުރެވޭ ޑޭޓާ Daffodil
  ދޫކޮށްލާތީ؛ ރޯތަކުގެ ދެމެދުގައި ބޭނުންކުރާ ސެޕަރޭޓަރަކުން، އޭގެ ބަދަލުގައި،
  ފަހު ނިއުލައިނަކުން އިތުރު ހުސް ރޯއެއް ހެދޭ.
- **ޑޭޓާ ނިމެންދެން ތަކުރާރުވާ ރެކޯޑެއް** 
  `<dfdl:assert testKind="pattern" testPattern="(?s)." .../>` އިން ރައްކާތެރި
  ކުރޭ. ހުސްވެދާނެ ލިޔުމުގެ ރެކޯޑެއް (މިސާލަކަށް ލިޔުމުގެ އެއް ފީލްޑް) ނޫންނަމަ
  ހަމަ ޑޭޓާގެ ނިމުމުގައި ކާމިޔާބުކަމާއެކު ޕާސް ވެ، Daffodil ހުއްޓެނީ "consumed no
  data and is stuck in an infinite loop" އާއެކު. ޕެޓަރން އެސާޝަނުން އެހެން
  ރެކޯޑެއް ފެށޭނީ މަދުވެގެން އެއް ބައިޓް ބާކީ ހުރިހާ ހިނދަކު ހަމައެކަނި.
- **ހިސާބުގެ ކުރިން ކުޑަ އިންޓީޖަރުތައް ކޮންވަޓް ކުރޭ.** އެކްސްޕްރެޝަނަކުން
  `xs:unsignedByte` (އަދި އެފަދަ) އަގުތައް ސީދާ ޖަމާ ކުރާއިރު ނުވަތަ
  އަޅާކިޔާއިރު، މިސާލަކަށް `{ . eq (../a + ../b) mod 256 }`، Daffodil 3.11
  ނާކާމިޔާބުވަނީ "Invariant broken ... ClassCastException: Integer cannot be
  cast to Short" އާއެކު؛ `{ xs:int(.) eq (xs:int(../a) + xs:int(../b)) mod 256 }`
  ލިޔޭ. އެ ސަބަބާހުރެ archive-manager ގެ ޖެނެރޭޓަރު ކޮންމެ އިންޓީޖަރ ފީލްޑެއްގެ
  ރިފަރެންސެއް `xs:integer(...)` ގެ ތެރޭގައި އޮޅާލާ.
- **`fn:sum` ނެތް.** Daffodil އެ ސަޕޯޓް ނުކުރާތީ، ވަކި ނޫން ޢަދަދެއްގެ އަގުތަކުގެ
  ޗެކްސަމެއް DFDL އެކްސްޕްރެޝަނެއްގައި ހިސާބު ނުކުރެވޭނެ؛ ނަން ދީފައިވާ ފީލްޑްތަކުގެ
  ޗެކްތައް ކުރެވޭ (archive-manager ގެ އަތުން ލިޔުމުގެ މިސާލުތައް ބަލާ)، އަދި
  އޭގެ މައްޗަށް Java އިން ލިޔެފައިވާ ޚާއްޞަ ލޭޔަރެއް ބޭނުންވޭ.
- **ލޭޔަރުތަކުން** ޕާސް ކުރުމުގެ ކުރިން ޑޭޓާގެ ބައެއް ބަދަލުކުރޭ: Daffodil 3.11
  ގައި `gzip`، `base64_MIME`، `fourbyteswap`/`twobyteswap`،
  `lineFolded_IMF`/`lineFolded_iCalendar`، `boundaryMark` އަދި `fixedLength`
  ލޭޔަރުތައް ހިމެނޭ. ލޭޔަރުގެ ސްކީމާ `/org/apache/daffodil/layers/xsd/` އިން
  އިމްޕޯޓްކޮށް، ސީކުއެންސަކަށް `dfdlx:layer="gz:gzip"` ލާ، އޭގެ ވަށައިގެންވާ
  `fl:fixedLength` ލޭޔަރަކުން ހަދުކޮށް، އޭގެ ދިގުމިން
  `dfdl:newVariableInstance` އިން ސެޓް ކުރޭ.
- **ބިޓް ފީލްޑްތަކަށް** `dfdl:lengthUnits="bits"` އާއި
  `dfdl:alignmentUnits="bits"` ބޭނުންވޭ؛ އެއްޗެހީގެ ފަހުން އަންނަ ބައިޓެއްގެ
  ސައިޒުގެ އެލިމެންޓެއް، ޑިފޯލްޓް އެއް ބައިޓްގެ އެލައިންމަންޓުން، ދެން އަންނަ
  ފުރިހަމަ ބައިޓަށް އެލައިން ކުރެވޭ.

## ޑޭޓާ އަނބުރާ ލިޔުން

`DfdlStructureRepInfo` އަކީ `WritableStructureRepInfo` އެއް: `write(dataObject, changes)` އިން
Daffodil ގެ DOM އިންފޮސެޓަށް ޕާސްކޮށް، ބަދަލުކުރި ކޮންމެ އެލިމެންޓެއްގެ ލިޔުން ސެޓްކޮށް (`ElementPath` ->
އަގު)، Daffodil ގެ އަންޕާސަރުން މުޅި އިންފޮސެޓް އަލުން އެންކޯޑް ކުރޭ؛ `roundTrip(dataObject)` އިން
ބަދަލެއް ނެތި އެ އަނބުރާ ލިޔެ އަޅާކިޔާ. ސްކީމާއިން ތަފްސީލުކުރާ ކޮންމެ އެއްޗެއް އޭގެ އަގުން އަލުން
އެންކޯޑް ކުރެވޭތީ، ދިގުމިނާއި ޢަދަދުތައް ދޭ އެލިމެންޓްތައް އެއާ ގުޅޭގޮތަށް ބަދަލުކޮށްފިނަމަ (ނުވަތަ
`dfdl:outputValueCalc` އިން ހިސާބުކޮށްފިނަމަ) އެއްޗެހި ބަދަލުވެދާނެ. އިންފޮސެޓުގައި ނެތް އެއްޗެއް ކިޔުނު
ގޮތަށް ނުލިޔެވޭ: ތަފްސީލުކުރި ޑޭޓާގެ ފަހުގައިވާ ބައިޓްތައް، ސާފު ދިގުމިނެއްގެ އެލިމެންޓެއްގެ ތެރޭގައި
ބޭނުން ނުކުރާ ބައިޓްތައް (ފިލް ބައިޓެއްގެ ގޮތުގައި ލިޔެވޭ)، އަދި ޑޭޓާގައި ބޭނުންކުރީ އެތައް
ޑިލިމިޓަރެއް ނުވަތަ ޓާމިނޭޓަރެއްގެ ތެރެއިން ކޮން އެއްޗެއްކަން (ފުރަތަމަ އެއްޗެއް ލިޔެވޭ - މިސާލަކަށް
ނިއުލައިނެއް ނެތް ފަހު ލައިނަކަށްފަހު ނިއުލައިނެއް).

`encode(infoset)` އިން އަސްލެއް ނެތި، ހަމައެކަނި އަގުތަކުން އައު ފައިލެއް ލިޔޭ: އިންފޮސެޓަކީ ސްކީމާގެ
އެލިމެންޓްތަކުގެ XML ޑޮކިއުމެންޓެއް، އޭގެ ނޭމްސްޕޭސްގައި އަދި ތަރުތީބުން، އަގުތައް ލިޔުމެއްގެ ގޮތުގައި
ހިމެނޭ. `DfdlSchemaOutline.read(schemaText)` އިން އެފަދަ އިންފޮސެޓެއް ތަބާވާ އެލިމެންޓް ޓްރީ ދޭ - ނަންތައް،
ނޭމްސްޕޭސްތައް، ކޮންމެ އެއްޗެއް ފެންނަ ފަހަރު، އަގުގެ ބާވަތް، ހިސާބުކުރާ އެއްޗެހި (`dfdl:outputValueCalc`)
އަދި އިޚްތިޔާރެއްގެ ބަދަލުތައް - ސްކީމާ XML Schema އެއްގެ ގޮތުގައި ކިޔައި، ހަމަ އެ ޑޮކިއުމެންޓްގެ ތެރޭގައި
ނަން ދީފައިވާ ބާވަތްތަކާއި އެލިމެންޓް ރިފަރެންސްތަކަށް ތަބާވެގެން. archive-manager ގެ ޓްރާންސްފޯމޭޝަނުން
ޑޭޓާ އޮބްޖެކްޓެއް އެހެން ފޯމެޓަކަށް އަލުން ލިޔުމަށް އިންފޮސެޓްތައް ބިނާކުރަނީ މިގޮތަށް.

## އެނގިފައިވާ ހަދުތައް

- ބޭނުންކުރެވޭނީ ސްކީމާގެ ޑިފޯލްޓް ރޫޓް އެލިމެންޓް ހަމައެކަނި.
- ބާވަތާއެކު އަގުތަކަށް ކުރާ ދެވަނަ ޕާސަކީ ކުރެވޭ ވަރަކުން ކުރާ އެއްޗެއް: ފުރަތަމަ
  ޕާސް ނާކާމިޔާބު ނުވާ ގޮތަކަށް އެ ނާކާމިޔާބުވެއްޖެނަމަ (Daffodil އިން އެތެރޭގެ
  "Abort" އެރަރެއް ދިމާކޮށްދެވިދާނެ)، އަގުތައް ސާދާކޮށް DOM ލިޔުމެއްގެ ގޮތުގައި
  އަނބުރާ އަންނާނެ.
- Daffodil 3.11 ގައި ބައިޓްގެ ތަންތަނެއް ނެތް (މަތީގައި ބަލާ).
- ބާވަތާއެކު އަގުތަކަށް ކުރާ ދެވަނަ ޕާހުން ޕާސް ކުރުމުގެ މަސައްކަތް ދެގުނަ ކޮށް،
  މުޅި ޑިޖިޓަލް އޮބްޖެކްޓް މެމޮރީގައި ބަހައްޓާ.
