Write it out

Download as BagIt → BagIt, referring to the bits → This Archival Information Package as a BagIt bag (RFC 8493), zipped: data/aip.ttl describes the AIP and everything it's made of, with its Data Objects' bits, each description as a file, and the OAIS ontologies, all with SHA-256 checksums — complete, to hand to another archive. Or refer to the Data Objects' bits rather than include them: fetch.txt gives the URL to fetch each from (its storage location), for large data or bits kept where the receiver can fetch them; the manifest still has their checksums, so the bag is complete once they're fetched.

Open the data

This Data Object's bits have a storage location, and its Representation Information says how to read them. Its Representation Information manifest (Turtle) names the data and each description explicitly; TOPCAT (with the oais-structure-topcat reader, format OAIS-RepInfo) and SPLAT open it by that address.

VOTable → FITS →

"View with TOPCAT" or "SPLAT" sends the data, decoded on the server as a VOTable, to that application running on your computer (over SAMP; it asks you to allow this page). SPLAT is offered when the table's columns are all numeric, as a spectrum's are. The VOTable link works in any VO tool. The same choices are on the Data Object's right-click menu in the graph.

Its Representation Information also says how to see it as an image. "View with DS9" or "Aladin" sends the image, decoded on the server as FITS, to that application running on your computer (over SAMP). Fiji/ImageJ doesn't use SAMP: open the FITS link's file in it, or give it the link's address with File › Import › URL. The FITS header carries the pixels' units and meaning.

Launch TOPCAT → Launch SPLAT →

No TOPCAT or SPLAT on your computer? "Launch" starts the application with this data already loaded, downloaded from the archive, with nothing to install or connect — once you have OpenWebStart (free, installed once; it opens the .jnlp file the link downloads). The application is signed with this archive's own self-signed certificate: the first time, OpenWebStart asks whether to trust it; choose to always trust this publisher, and later launches won't ask.

The first page of a large file takes a while to decode; the pages after it don't.
