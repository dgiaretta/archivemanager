Open the data

This Data Object's bits have a storage location, and its Representation Information says how to read them. Its Representation Information manifest (Turtle) names the data and each description explicitly; TOPCAT (with the oais-structure-topcat reader, format OAIS-RepInfo) and SPLAT open it by that address.

VOTable → FITS →

"View with TOPCAT" or "SPLAT" sends the data, decoded on the server as a VOTable, to that application running on your computer (over SAMP; it asks you to allow this page). SPLAT is offered when the table's columns are all numeric, as a spectrum's are. The VOTable link works in any VO tool. The same choices are on the Data Object's right-click menu in the graph.

Its Representation Information also says how to see it as an image. "View with DS9" or "Aladin" sends the image, decoded on the server as FITS, to that application running on your computer (over SAMP). Fiji/ImageJ doesn't use SAMP: open the FITS link's file in it, or give it the link's address with File › Import › URL. The FITS header carries the pixels' units and meaning.

It has no DFDL or DRB SDF description with a table or image view to decode it by on the server; saving its description again from RepInfo Tools adds one.
