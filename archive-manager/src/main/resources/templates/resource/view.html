Open the data

This Data Object's bits have a storage location, and its Representation Information says how to read them. Its Representation Information manifest (Turtle) names the data and each description explicitly; TOPCAT (with the oais-structure-topcat reader, format OAIS-RepInfo) and SPLAT open it by that address.

VOTable →

"View in TOPCAT" sends the data, decoded on the server as a VOTable, to TOPCAT running on your computer (over SAMP; TOPCAT asks you to allow it). The VOTable link works in any VO tool.

It has no DFDL or DRB SDF description with a table view to decode it by on the server; saving its description again from RepInfo Tools adds one.
