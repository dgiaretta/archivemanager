Archive Manager

A small archive-management application over RiC-O 1.1 and the OAIS Information Model, connected by a custom bridging ontology. Records are described natively in RiC-O; the OAIS mapping view on each record shows the corresponding OAIS classes and, where the sample data links one, the actual OAIS preservation-description structure for the same holdings.

Data lives in Apache Jena TDB2, a real disk-backed transactional triple store, at data/tdb2. Every change commits as part of the request that made it — there's no separate save step, and it survives restarts.
