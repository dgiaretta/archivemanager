އެހީ

މި އެޕްލިކޭޝަނަކީ ކޮބާ

މިއީ ޕްރޮޓޮޓައިޕް އާކައިވެއް. މިއިން މަޢުލޫމާތާއި ރެކޯޑްތައް ބަލައިގަނެ — ރެކޯޑްސް މެނޭޖްމަންޓްގެ ބަހުން އެކްސެޝަން، OAIS ގެ ބަހުން އިންޖެސްޓް — އާންމުކޮށް ވަކިވަކި ސިސްޓަމްތަކުގައި ހުންނަ ދެ ދާއިރާއެއް އެއްކޮށްލައެވެ:

  • ރެކޯޑްސް މެނޭޖްމަންޓް، Records in Contexts (RiC-O، އާކައިވްސްގެ ބައިނަލްއަޤްވާމީ ކައުންސިލްގެ އޮންޓޮލޮޖީ) ބޭނުންކޮށްގެން. އެއިން ރެކޯޑްތައް ތަފްސީލުކުރޭ: އެއީ ކޮބައިކަން، އެ އުފެއްދީ ކާކުކަން، ކޮން ހަރަކާތްތަކެއްގައި އަދި ކޮން މެންޑޭޓްތަކެއްގެ ދަށުންކަން، އަދި އެއްބައި އަނެއްބައިއާ ގުޅޭ ގޮތް، ހެކިތަކެއްގެ ގޮތުގައި ހޯދައި ވިސްނޭނެ ގޮތަށް.
  • ޑިޖިޓަލް ޕްރިޒަވޭޝަން، OAIS (Open Archival Information System ރިފަރެންސް މޮޑެލް، ISO 14721 / CCSDS 650.0-M-3) ބޭނުންކޮށްގެން. އެއިން މަޢުލޫމާތު ހިފެހެއްޓޭ، ސޮފްޓްވެއަރ، ހާޑްވެއަރ އަދި ޢިލްމު ބަދަލުވާއިރު ވެސް ބޭނުންކުރެވި ވިސްނޭނެ ގޮތަށް، OAIS ގެ ތިން އަސާސީ ޕްރިޒަވޭޝަން އުސޫލު ބޭނުންކޮށްގެން: ރެޕްރެޒެންޓޭޝަން މަޢުލޫމާތު އިތުރުކުރުން، ޓްރާންސްފޯމޭޝަން، އަދި ފުރިހަމަ ޕެކޭޖްތައް އެހެން އާކައިވަކަށް ހަވާލުކުރުން.

ބްރިޖް އޮންޓޮލޮޖީއަކުން މި ދެކަން ގުޅުވާ، އެހެންކަމުން RiC-O އިން ތަފްސީލުކުރި ރެކޯޑަކުން އެ ހިފެހެއްޓޭ OAIS ޕެކޭޖަށް ދައްކާލެވޭނެ، އަދި އަނބުރާ ވެސް. ދެކަމެއް ވެސް ލިންކްޑް ޑޭޓާ (RDF) ގެ ގޮތުގައި އެއް ސްޓޯރެއްގައި ރައްކާކުރެވިފައި، އެހެންވީމާ ހުރިހާ އެއްޗެއް އެކުގައި ބެލުމާއި، ގްރާފް ކުރުމާއި، ކުއެރީ ކުރެވޭނެ.

މި ޞަފްޙާ ދަނީ މަޢުލޫމާތުގެ ދިރިއުޅުމާ އެއްގޮތަށް: ފުރަތަމަ އެ ބަލައިގަނެ، ތަފްސީލުކޮށް، އޭގެ ރެޕްރެޒެންޓޭޝަން މަޢުލޫމާތު ހަދައި، އެ ގުޅޭ ގޮތް ބަލައި، އަދި ކޮންމެ އާކައިވަލް އިންފޮމޭޝަން ޕެކޭޖެއްގައި OAIS އިން ބޭނުންވާ ހުރިހާ ބައެއް ހުރިތޯ ޗެކްކުރާނެ ގޮތް؛ ދެން ތިން ޕްރިޒަވޭޝަން އުސޫލު؛ ދެން ޑޭޓާ ބަލައި ތަހުލީލުކުރާނެ ގޮތް.

އެސްޓްރޮނޮމީގެ އެޕްލިކޭޝަންތައް ކީއްވެ؟ ހިފެހެއްޓި ޑޭޓާ ހަގީގަތުގައި ބޭނުންކުރެވޭކަން ދެއްކުމަށް، މި ޕްރޮޓޮޓައިޕުން އެ ހުޅުވަނީ އެސްޓްރޮނޮމީގެ ޓޫލްތަކުގައި: ތާވަލްތަކާއި ސްޕެކްޓްރާއަށް TOPCAT އާއި SPLAT، ފޮޓޯތަކަށް DS9 އާއި Aladin. އެއްޗެހި ހޮވީ، އެއީ ދުރުގައިވާ އާކައިވްތަކުން ޑޭޓާ ލިބިގަނެ، ދެން އެތައް ތަފާތު މަސްދަރަކުން ލިބޭ މަޢުލޫމާތު ތަހުލީލުކޮށް، އަޅާކިޔައި، ގުޅުވުމަށް ތަރުތީބުކޮށްފައިވާ ޓޫލްތަކަކަށް ވާތީ (އެއްޗެހި އެކަކު އަނެކަކާއި، އަދި އާކައިވްތަކާ ގުޅެނީ VOTable އާއި SAMP ފަދަ ވާޗުއަލް އޮބްޒަވޭޓަރީގެ ސްޓޭންޑަޑްތަކުން). އާކައިވެއްގެ ޑޭޓާއަށް ބޭނުންވަނީ ހަމަ މިއީ. ނަމަވެސް އެއްވެސް އެއްޗެއް އެއްޗެހި މައްޗަށް ބަރޯސާއެއް ނުވޭ: އާކައިވުން ޑޭޓާ ދެނީ ސްޓޭންޑަޑް ފޯމެޓްތަކުން، އޭގެ ރެޕްރެޒެންޓޭޝަން މަޢުލޫމާތުން ތަފްސީލުކޮށްފައި، އެހެންވީމާ އެއްޗެހީގެ ބަދަލުގައި އެހެން އެޕްލިކޭޝަންތައް ބޭނުންކުރެވިދާނެ.

އާކައިވާއެކު މަސައްކަތްކުރުން

ބަލާލުން — ލޮގިން ނުވެ

އެކައުންޓެއް ނެތި ހުރިހާ އެއްޗެއް ބެލޭނެ. ކެޓަލޮގް އާއި އެކްސެޝަން ރަޖިސްޓަރީ އަކީ އާންމު ހޯދުމާއި ބެލުމުގެ ވިއުތައް. ކޮންމެ ރެކޯޑަކުން، ރެކޯޑްތައް، އޭޖެންޓުން، ޕްރޮވެނަންސް ހާދިސާތައް އަދި މެންޑޭޓްތައް އެކަކު އަނެކަކަށް ލިންކް ކުރޭ (އޭޖެންޓެއްގެ ޞަފްޙާގައި އެ ފަރާތުން އުފެއްދި އެއްޗެހި ލިސްޓްކޮށްފައި، ފަދައިން)، އަދި އެންޓިޓީތައް ގައި ކޮންމެ ބާވަތެއްގެ ހުރިހާ އެއްޗެއް ލިސްޓްކޮށްފައި.

އެއްޗެއް ބަލައިގަތުމަށް ނުވަތަ ބަދަލުކުރުމަށް ލޮގިން ކުރުން

މަޢުލޫމާތު ބަލައިގަތުމާއި، އެޑިޓް ކުރުމާއި، ރެޕްރެޒެންޓޭޝަން މަޢުލޫމާތު ހެދުމާއި، ހިފެހެއްޓުމަށް ހިއްސާކުރެވިފައިވާ އެޑިޓް ޕާސްވޯޑް ބޭނުންވޭ: ލޮގިން ކުރޭ. ބެލުމާއި، ވިއުކުރުމާއި، ޑައުންލޯޑް ކުރުން ކޮންމެ ބޭފުޅަކަށް ހުޅުވާލެވިފައި.

މަޢުލޫމާތު ބަލައިގަތުން (އެކްސެޝަން އަދި އިންޖެސްޓް)

  • ރެކޯޑްތައް، އެއްކޮށް: ބަލްކް އަޕްލޯޑް ސްޕްރެޑްޝީޓް (ކެޓަލޮގް ޞަފްޙާއިން ލިންކްކޮށްފައި) އިން NAM ގެ ފޯމެޓްގައިވާ ރެކޯޑްތަކުގެ CSV ނުވަތަ XLSX އެއް އެއް ފަހަރާ އިމްޕޯޓް ކުރޭ، ކޮންމެ ރެކޯޑަކާއި، އޭގެ އުފެއްދި ފަރާތާއި، އައިޑެންޓިފަޔަރުތަކާއި، ކޮންމެ ރެކޯޑަކާ ގުޅުވައިފައިވާ OAIS ޕެކޭޖެއް (ކޮންޓެންޓް މަޢުލޫމާތާއި ޕްރިޒަވޭޝަން ޑިސްކްރިޕްޝަން މަޢުލޫމާތު) ހަދައިގެން؛ މުޅި އަޕްލޯޑް ރެކޯޑް ކުރެވެނީ އެކްސެޝަން ރަޖިސްޓަރީގައި އެއް އެކްސެޝަނެއްގެ ގޮތުގައި.
  • ކޮންމެ ލިންކްޑް ޑޭޓާއެއް: /entities/import (އެންޓިޓީތައް އިން ލިންކްކޮށްފައި) އިން ޕޭސްޓްކުރި Turtle (RDF) ޑޮކިއުމެންޓެއް ލޯޑް ކުރޭ — ރެކޯޑްތައް، OAIS ޕެކޭޖްތައް، ކޮންމެ އެއްޗެއް — އެއްވެސް އެއްޗެއް އިތުރުކުރުމުގެ ކުރިން މުޅިން ޗެކްކޮށްގެން.
  • އެއް ފަހަރާ އެއް އެއްޗެއް: އެންޓިޓީތައް އިން ކޮންމެ RiC-O ނުވަތަ OAIS ކްލާހެއްގެ އިންޑިވިޖުއަލެއް ހަދާ؛ ރެކޯޑްތައް އިން ރެކޯޑްތައް ހަދާ.
  • ޑޭޓާއާއި އޭގެ ތަފްސީލު: RepInfo ޓޫލްސް އިން ޑޭޓާ ފޯމެޓެއްގެ ތަފްސީލު، ޑޭޓާއަށް ޑޭޓާ އޮބްޖެކްޓަކާއެކު، އާކައިވްގައި ރައްކާކުރޭ (ތިރީގައި ބަލާ).
  • ބިޓްތައް: އާކައިވުން ރައްކާކުރަނީ ތަފްސީލުތައް، ޑޭޓާ ފައިލްތަކެއް ނޫން. ޑޭޓާ އޮބްޖެކްޓަކުން އޭގެ ބިޓްތައް ރައްކާކޮށްފައިވާ ތަން ދައްކަނީ im:hasStorageLocation އިން — މިސާލަކަށް Dropbox ނުވަތަ ކްލައުޑް ސްޓޯރޭޖް ލިންކެއް — ޑޭޓާ ކިޔަން ބޭނުންވާއިރު އާކައިވުން އެ ލިބިގަންނަނީ އެތަނުން. ޓްރާންސްފޯމޭޝަނެއްގެ ނަތީޖާ ފަދަ، އާކައިވް އަމިއްލައަށް ހަދާ ބިޓްތައް ރައްކާކުރެވެނީ އޭގެ އަމިއްލަ ސްޓޯރުގައި.

ރެކޯޑްތައް ތަފްސީލުކުރުމާއި، ޕްރޮޕަޓީތަކާއި ގުޅުންތައް އެޑިޓް ކުރުން

ރެކޯޑްތައް ތަފްސީލުކުރެވެނީ RiC-O އިން: ރެކޯޑެއް، ރެކޯޑްގެ ބައެއް ނުވަތަ ރެކޯޑް ސެޓެއް، އޭގެ ސުރުހީއާއި ތަފްސީލު، އެ އުފެއްދި ފަރާތް (އޭޖެންޓެއް)، އެ ލިބުނު ހަރަކާތްތައް، އެ ތަނފީޒުކުރާ މެންޑޭޓްތައް، އޭގެ އައިޑެންޓިފަޔަރުތަކާއި ތާރީޚްތައް، އަދި އެ ބައިވެފައިވާ ރެކޯޑްތައް.

ކޮންމެ އިންޑިވިޖުއަލެއްގެ ޞަފްޙާގައި އެޑިޓް ހުރި، އެއިން އާންމު އެޑިޓަރު ހުޅުވޭ: އޭގެ ބާވަތްތަކާއި، ޕްރޮޕަޓީތަކާއި (ލިޔުން، ނަންބަރު، ތާރީޚް، ލިންކް)، އެހެން އިންޑިވިޖުއަލުންނާ ގުޅުންތައް، އެއް ފަހަރާ އެއް އެއްޗެއް، RiC-O އާއި OAIS އިން އެއަށް ކަނޑައަޅާފައިވާ ޕްރޮޕަޓީތަކުގެ ތެރެއިން ހޮވައިގެން އިތުރުކުރުން ނުވަތަ ނައްތާލުން. ގުޅުމެއް އިތުރުކުރާއިރު، ބޭނުންވާ އެއްޗެއް ހޮވާ ތަނުގައި "+ އައު އެއްޗެއް ހަދާ …" ފެންނާނެ، އެހެންވީމާ އެ ދައްކާ އެއްޗެއް ކުރިން ހުންނަން ނުޖެހޭ — އެ ހެދި ގުޅުވެނީ ހަމަ އެ ފިޔަވަޅުގައި.

ރެޕްރެޒެންޓޭޝަން މަޢުލޫމާތު ހެދުން

ރެޕްރެޒެންޓޭޝަން މަޢުލޫމާތަކީ ޑޭޓާ އޮބްޖެކްޓެއްގެ ބިޓްތައް ވިސްނުމަށް ބޭނުންވާ އެއްޗެއް: އެއްޗެހީގެ ބިނާ (ބިޓްތަކުން ނަންބަރު، ލިޔުން، ރެކޯޑް އަދި އެރޭ ހެދޭ ގޮތް)، އެއްޗެހީގެ ސިމެންޓިކްސް (ކޮންމެ އަގެއްގެ މާނަ، ކޮން ޔުނިޓަކުން)، އަދި އެއްޗެހި ކިޔާ ސޮފްޓްވެއަރ ފަދަ އެހެނިހެން ރެޕްރެޒެންޓޭޝަން މަޢުލޫމާތު.

  • ބައިނަރީ އަދި އަމިއްލައަށް ތަފްސީލުކުރާ ފޯމެޓްތައް: RepInfo ޓޫލްސް އަކީ ޑޭޓާ ފޯމެޓެއްގެ Kaitai Struct، DFDL އަދި DRB ތަފްސީލުތައް ބިނާކުރުމަށް ގައިޑްކުރާ އެޑިޓަރެއް (FITS، ޓެލެމެޓްރީ، CSV އަދި HDF5 ފެށުމުގެ ނުކުތާތަކާއެކު، އަދި ކޮންމެ FITS ފައިލެއް އޭގެ އަމިއްލަ ހެޑަރުތަކުން ތަފްސީލުކޮށްގެން). ބައިޓް ލޭއައުޓެއް އެޑިޓް ކުރެވެނީ ފީލްޑްތަކާއި، ރެކޯޑްތަކާއި (CSV ގޮތުގެ ވަކިކޮށްފައިވާ ލިޔުމުގެ ރެކޯޑް ހިމެނޭގޮތަށް)، އިޚްތިޔާރުތަކުގެ ޓްރީއެއްގެ ގޮތުގައި؛ ކޮންމެ އެލިމެންޓެއް ޝަރުތަކާއެކު އިޚްތިޔާރީ ކުރެވޭނެ ނުވަތަ ހިސާބުކުރެވޭ ޢަދަދަކަށް ތަކުރާރު ކުރެވޭނެ، sample_pairs * 2 ނުވަތަ packet_type = 2 ފަދަ، ކުރިން ކިޔުނު ފީލްޑްތަކަށް ރިފަރކުރާ ކުޑަ އެކްސްޕްރެޝަންތަކުން. ކޮންމެ އެލިމެންޓަކަށް އޭގެ ސިމެންޓިކްސް ދޭ — ސިމެންޓިކް ނަމެއް، ތަޢުރީފެއް، ޔުނިޓް (ވޮކެބިއުލަރީ ލިންކަކާއެކު)، ކޯޑް ލިސްޓެއް، ސްކޭލް ފެކްޓަރަކާއި އޮފްސެޓެއް، ފިލް އަގެއް އަދި ސައްޙަ ރޭންޖެއް. ސޭވް ކުރުމުގެ ކުރިން ޖެނެރޭޓްކުރި ކޮންމެ ތަފްސީލެއް ނަމޫނާ ފައިލަކާ ދެކޮޅަށް ޓެސްޓް ކުރޭ: ޓެސްޓްތަކުން ކޮންމެ އަގެއްގެ މާނަ (ކޯޑެއްގެ މާނަ ނުވަތަ ޔުނިޓާއެކު ސްކޭލް ކުރެވިފައިވާ އަގު)، ކޮންމެ އިޚްތިޔާރަކުން ހޮވި ބްރާންޗް، އަދި ތަފްސީލުގައި ނުހިމެނޭ ބައިޓްތައް ދައްކާ. ކޮންމެ ތަފްސީލަކުން ނަމޫނާއެއް އަނބުރާ ލިޔެވެސް ދެވޭނެ، ނަތީޖާ ބައިޓަށް ބައިޓް އެއްގޮތްތޯ ޗެކްކުރުމަށް (އޭރުން ފައިލް އަލުން ހެދުމަށް ތަފްސީލު ފުދޭ) ނުވަތަ ބައެއް އަގުތައް ބަދަލުކޮށްގެން ކޮޕީއެއް ލިޔުމަށް.
  • ލެންގުއޭޖްތައް ހޮވުން: ހުރިހާ ލެންގުއޭޖެއް ޖެނެރޭޓް ކުރުމުން ތަފްސީލު ހަނިވަނީ ކޮންމެ ލެންގުއޭޖަކަށް ފާޅުކުރެވޭ އެއްޗަކަށް؛ މަދު އަދަދެއް ހޮވުމުން އެ ލެންގުއޭޖްތަކަށް ހަމައެކަނި ތަފްސީލުކުރެވޭ ކަންކަން ހުޅުވޭ، ބިޓް ފީލްޑް، ސައިޒު ކަނޑައަޅާފައިވާ ރެކޯޑް، nil އަގު، ކޯޓްކުރި CSV އަދި ނަންބަރު ފޯމެޓް (DFDL)، ނުވަތަ ސާބިތު ތަނެއްގައިވާ އެލިމެންޓްތަކާއި zlib އިން ކޮމްޕްރެސްކުރި ރެކޯޑް (Kaitai Struct) ފަދަ. އެޑިޓަރަށް ފާޅުނުކުރެވޭ ކޮންމެ އެއްޗަކަށް — ޗެކްސަމް، އެންކްރިޕްޝަން، އެހެން ކޮމްޕްރެޝަން — ތަފްސީލު އަތުން ލިޔޭ، ފެށުމުން ފެށިގެން ނުވަތަ ޖެނެރޭޓްކުރި އެއްޗެއް ފުޅާކޮށްގެން. ބައިޓް ލޭއައުޓަކަށް DRB އައުޓްޕުޓަކީ އިންސްޓޯލް ކުރެވޭ drb-python ޑްރައިވަރ ޕެކޭޖަކާއި GAEL ގެ Java DRB އަށް DRB SDF ސްކީމާއެއް؛ ޑްރައިވަރުގައި އެޑް-އޮންތައް (ސިމެންޓިކްސް، މެޓަޑޭޓާ، ޗެކްތައް) އަދި އަތުން ލިޔުނު Python އެޑް-އިނެއް ހިމެނިދާނެ (ސާވަރުން ހުއްދަ ދީފިނަމަ ހަމައެކަނި ނަމޫނާ ޓެސްޓްތަކުގައި ހިނގާ).
  • EAST، CCSDS ގެ ޑޭޓާ ޑިސްކްރިޕްޝަން ލެންގުއޭޖް (CCSDS 644.0-B-3)، އެހެން ލެންގުއޭޖްތަކެއް ފަދައިން އެލިމެންޓް ޓްރީއިން ޖެނެރޭޓް ކުރެވި، EAST އަށް ބުނެވޭ ހުރިހާ އެއްޗެއް ކިޔާ EAST އިންޓަޕްރެޓަރަކުން ނަމޫނާ ފައިލަކާ ދެކޮޅަށް ޓެސްޓް ކުރެވޭ: މާކަރ، VAX، MIL-STD-1750A، CDC އަދި IBM މެޝިންތަކުގައި ލިޔެފައިވާ ރިއަލް، ބައިބަޔަށް ހުންނަ އިންޓީޖަރ، އަދި އެހެނިހެން. ޑޭޓާ ޑިސްކްރިޕްޝަން ރެކޯޑެއް އަޕްލޯޑް ނުވަތަ ޕޭސްޓް ވެސް ކުރެވޭނެ: އެ ރައްކާކުރެވެނީ ލިޔެފައިވާ ގޮތަށް، އަދި އޭގެ ރެކޯޑް، އެރޭ، އީނިއުމަރޭޝަން އަދި ވޭރިއަންޓްތައް ވާނީ އެލިމެންޓް ޓްރީއަށް، އެއިން އެހެން ލެންގުއޭޖްތައް ޖެނެރޭޓް ކުރެވޭ — ނުވަތަ ޓްރީއަށް އެ ފާޅުނުކުރެވޭނަމަ، EAST ގައި ހަމައެކަނި ރައްކާވާނެ.
  • ސޮފްޓްވެއަރަށް ކުރިން ކިޔޭ ފޯމެޓްތައް (.xlsx، .xls، .ods، .csv): ކޮންމެ ކޮލަމެއްގެ މާނަ ހަމައެކަނި ތަފްސީލުކުރޭ — ކޮލަމްތައް ނަމޫނާ ފައިލަކުން ނެގޭނެ. އެ ރައްކާކުރެވެނީ ފޯމެޓް ޕްރޮފައިލަކާއި (ފޯމެޓްގެ ރަޖިސްޓްރީ އައިޑެންޓިފަޔަރ، އޭގެ ވަރޝަނާއި، ލިޔުމަށް ނަމަ، އޭގެ ކެރެކްޓަރ އެންކޯޑިންގއާއި ޑިލިމިޓަރާއެކު ސާފުކޮށްފައި) އެ ކިޔާ ސޮފްޓްވެއަރާއެކު.
  • ސޭވް ކުރުމުން އެ އާކައިވަށް އިތުރުވަނީ ހަގީގީ ރެޕްރެޒެންޓޭޝަން މަޢުލޫމާތެއްގެ ގޮތުގައި، ޑޭޓާ އޮބްޖެކްޓަކާ ގުޅިގެން: ސްޓްރަކްޗަރ ރެޕްރެޒެންޓޭޝަން މަޢުލޫމާތު (އެއްވަރުގެ އެތައް ތަފްސީލެއް، ކޮންމެ އެއްޗެއް ވެސް ކަމުދޭ)، އަދި ކޮންމެ އެލިމެންޓަކަށް އެއް ސިމެންޓިކް ރެޕްރެޒެންޓޭޝަން މަޢުލޫމާތު، ތަފްސީލު ފަދައިން އެކަކު އަނެކަކުގެ ތެރޭގައި، އޭގެ ނަމާއި، ތަޢުރީފާއި، ޔުނިޓާއި، ކޯޑް ލިސްޓާއެކު. އެހެން ކޮންމެ އެއްޗެއް — ސްޕެސިފިކޭޝަން ޑޮކިއުމެންޓެއް، ޑިކްޝަނަރީއެއް، އެހެން ސޮފްޓްވެއަރެއް — އެޑިޓަރުން އިތުރުކުރެވޭނެ.
  • އެ ބޭރަށް ލިޔުން: ސޭވް ކުރުމުގެ ކުރިން، ޕްރިވިއު ޞަފްޙާއިން ކޮންމެ ތަފްސީލެއް ޑައުންލޯޑް ކުރެވޭ (.ksy، .dfdl.xsd، .drb.xsd، drb-python ޕެކޭޖް). ސޭވް ކުރުމަށްފަހު، ޑޭޓާ އޮބްޖެކްޓްގެ ޞަފްޙާގައި، ނުވަތަ ކޮންމެ ރެޕްރެޒެންޓޭޝަން މަޢުލޫމާތެއްގެ ޞަފްޙާގައި ހުންނަ ޑޭޓާގެ ތަފްސީލު ޑައުންލޯޑް ކުރޭ އިން ހުރިހާ އެއްޗެއް zip އެއްގެ ގޮތުގައި ދޭ: RDF ގައި description.ttl، އަދި ކޮންމެ ތަފްސީލަކާއި ވިއު ސްޕެސިފިކޭޝަނެއް އަމިއްލަ ފައިލެއްގެ ގޮތުގައި.

ގުޅުންތައް ބެލުން

ރެކޯޑްތަކާއި އެއްޗެހީގެ OAIS ޕެކޭޖްތައް. RiC-O އާއި OAIS އިން ހަމަ އެއް މެޓީރިއަލްއާ ބެހޭގޮތުން ކުރަނީ ތަފާތު ސުވާލުތައް: RiC-O އިން، އެއްޗެއް އުފެއްދީ ކާކު، ކޮން ހާލަތެއްގައި، އަދި އެ އަލުން ހޯދާނެ ގޮތް؛ OAIS އިން، ބިޓްތަކަށް ދިހަވަރަކަށް އަހަރު ފަހުން ވެސް މާނައެއް ހުރުމަށް، އެއްޗެހިތަކާ އެކުގައި ރައްކާކުރަން ޖެހޭ އެއްޗެއް. އެދެމެދުގެ ކްލާސްތައް އެކަކާ އެކަކު ދިމާއެއް ނުވާތީ، ބްރިޖް އޮންޓޮލޮޖީން އެއްޗެހި ދެގޮތަކަށް ގުޅުވާ: SKOS closeMatch/broadMatch/relatedMatch ބޭނުންކޮށްގެން ކްލާސް ލެވެލްގެ ދިމާވުންތައް (ކޮންސެޕްޓްތައް އެއްގޮތް ނުވާ ތަންތަނުގައި ގަސްދުގައި owl:equivalentClass އަށްވުރެ ބަލި)، އަދި ރެކޯޑަކުން އެ ހިފެހެއްޓޭ OAIS ބިނާއަށް އިންޑިވިޖުއަލް ލެވެލްގެ bridge:hasOAISCounterpart ލިންކްތައް. ކޮންމެ ރެކޯޑެއް ހުޅުވައި، އޭގެ "OAIS މެޕިންގ" ލިންކަށް ގޮސް ދެކަމެއް ވެސް ބަލާ: އޭގެ RiC-O ބާވަތްތަކާ ދިމާވާ OAIS ކްލާސްތަކާއި، އޭގެ ހަގީގީ ގުޅުވައިފައިވާ OAIS ބިނާ.

ގްރާފް. ގްރާފް އިން މުޅި އާކައިވް ނެޓްވޯކެއްގެ ގޮތުގައި ދައްކާ؛ ކޮންމެ ޞަފްޙާއެއްގައިވާ "ގްރާފުގައި ބަލާ" އިން އެ އެއްޗެއްގެ ވަށައިގެން ފޯކަސްކުރި ވިއުއެއް ދައްކާ، ބަދަލުކުރެވޭ ފުންމިނަކާއެކު (1–4 ފިޔަވަޅު). ކޮންމެ ލިސްޓް ޞަފްޙާއެއްގައި، އަދި SPARQL ކޮންސޯލްގެ ނަތީޖާގައި ވެސް "މި ޞަފްޙާ ގްރާފެއްގެ ގޮތުގައި ބަލާ" ހުރި، އެއިން ސްކްރީނުގައިވާ އެއްޗެހި ހަމައެކަނި ގްރާފް ކުރޭ.

  • ކުލައިން ނޯޑެއް ނިސްބަތްވާ އޮންޓޮލޮޖީ ދައްކާ (ނޫ = RiC-O، ދޮންބުރު = OAIS، އަޅި = އެހެނިހެން)؛ ފަޅައިގެންވާ ރަތް އެޖަކީ ބްރިޖް އޮންޓޮލޮޖީގެ ތެރެއިން ހަދާފައިވާ ލިންކެއް.
  • މައުސް: ޒޫމް ކުރުމަށް ސްކްރޯލް ކުރޭ، ހިއްލުމަށް ފަސްގަނޑު ދަމާ، ނޯޑެއް ހިއްލުމަށް އެ ދަމާ، ނޯޑެއްގެ ޞަފްޙާ ހުޅުވުމަށް ދެފަހަރު ކްލިކް ކުރޭ.
  • ނޯޑަކަށް ރައިޓް ކްލިކް ކުރޭ "ތަފްސީލުގެ ޞަފްޙާ ހުޅުވާ" (އައު ޓެބެއްގައި)، އޭގެ ލިންކްތައް — ބިޓްތައް ޑައުންލޯޑް ކުރުމަށް im:hasStorageLocation ހިމެނޭގޮތަށް — އަދި ރެޕްރެޒެންޓޭޝަން މަޢުލޫމާތުން ބަލާނެ ގޮތް ބުނާ ޑޭޓާ އޮބްޖެކްޓަކަށް، "ޑޭޓާ ބަލާ" (ތިރީގައި ބަލާ) އަށް.
  • ހައިލައިޓް ކުރުން: ގްރާފްގެ މަތީގައިވާ ޗެކްބޮކްސްތަކުން (އެންޓިޓީ ބާވަތް، ނޯޑް ޕްރޮޕަޓީ، ގުޅުމުގެ ބާވަތް) ދިމާނުވާ ހުރިހާ އެއްޗެއް ބޮޅިކޮށްލާ؛ ގްރޫޕްތައް ގުޅުވުމުން އިތުރަށް ހަނިވޭ.
  • ވަރަށް ބޮޑު ވަށައިގެންވާ ތަނެއް ހަލުވިކޮށް ހުރުމަށް ކުރުކުރެވިދާނެ — ބެނަރަކުން އެކަން ބުނާނެ؛ ފޯކަސްކުރި ވިއުއެއް ނުވަތަ ކުޑަ ފުންމިނެއް ބޭނުންކުރޭ.

ކުއެރީ ކުރުން. SPARQL ކޮންސޯލް އިން ޑޭޓާއާއި އޮންޓޮލޮޖީތައް އެކުގައި ކޮންމެ SELECT ކުއެރީއެއް ހިންގާ — ފިކްސިޓީ މަޢުލޫމާތު ނެތް ޕެކޭޖްތަކަކީ ކޮބާ ފަދަ، އެއްވެސް ޞަފްޙާއަކުން ޖަވާބު ނުދޭ ސުވާލުތަކަށް.

OAIS އާކައިވަލް އިންފޮމޭޝަން ޕެކޭޖެއްގެ ބައިތައް

އާކައިވަލް އިންފޮމޭޝަން ޕެކޭޖް (AIP) އަކީ OAIS ހިފެހެއްޓޭ އެއްޗެއް: އޭގެ މަޢުލޫމާތު ވިސްނޭގޮތަށް ހުރުމަށް ބޭނުންވާ ހުރިހާ އެއްޗެއް، އެކުގައި ރައްކާކޮށްފައި. OAIS އިންފޮމޭޝަން މޮޑެލްއަށް ބަލާއިރު، AIP އެއްގައި ހުންނަނީ:

  • ކޮންޓެންޓް މަޢުލޫމާތު (ހަމަ އެކެއް): ކޮންޓެންޓް ޑޭޓާ އޮބްޖެކްޓް، އޭގެ ބިޓްތައް، އަދި އެއްޗެހި ތަފްސީރުކުރުމަށް ބޭނުންވާ ރެޕްރެޒެންޓޭޝަން މަޢުލޫމާތު؛
  • ޕްރިޒަވޭޝަން ޑިސްކްރިޕްޝަން މަޢުލޫމާތު (ހަމަ އެކެއް)، ރެފަރެންސް (އައިޑެންޓިފަޔަރުތައް)، ޕްރޮވެނަންސް (އޭގެ ތާރީޚް)، ކޮންޓެކްސްޓް (އޭގެ މާހައުލާއި އެހެން މަޢުލޫމާތާ ގުޅޭ ގޮތް)، ފިކްސިޓީ (ބަދަލެއް ނުވާކަމުގެ ޗެކްތައް) އަދި އެކްސެސް ރައިޓްސް މަޢުލޫމާތާއެކު (އެ ބޭނުންކުރެވޭނީ ކާކަށް، އަދި ކިހިނެއް)؛
  • ޕެކޭޖިންގ މަޢުލޫމާތު (ހަމަ އެކެއް): ބައިތައް އެކުގައި ބަނދެވިފައިވާ ގޮތާއި އެއްޗެހި ނަގާނެ ގޮތް؛
  • ޕެކޭޖް ޑިސްކްރިޕްޝަނެއް (މަދުވެގެން އެކެއް): ޕެކޭޖް ހޯދުމަށް.

ޑޭޓާ އޮބްޖެކްޓަކުން AIP އެއް ހެދުން. ޑޭޓާ އޮބްޖެކްޓެއްގެ ޞަފްޙާގައި AIP ހަދާ ހުރި، އެއިން އެ ވަށައިގެން AIP އެއް ހަދަނީ އާކައިވަށް އެނގޭ ނުވަތަ ހޯދޭ ހުރިހާ އެއްޗަކާއެކު: އޭގެ ކޮންޓެންޓް މަޢުލޫމާތު (ޑޭޓާ އޮބްޖެކްޓާއި، އެ ތަފްސީރުކުރާ ރެޕްރެޒެންޓޭޝަން މަޢުލޫމާތު)؛ ފިކްސިޓީ މަޢުލޫމާތު، އޭގެ ބިޓްތަކުގެ SHA-256 އާއި ސައިޒު، އެވަގުތު އެއްޗެހީގެ ސްޓޯރޭޖް ލޮކޭޝަނުން ލިބިގަނެގެން؛ ރެފަރެންސް މަޢުލޫމާތު (އޭގެ އައިޑެންޓިފަޔަރުތަކާއި އޭގެ ބިޓްތައް ހުރި ތަން)؛ ޕްރޮވެނަންސް މަޢުލޫމާތު (AIP ހެދުނީ ކޮން އިރަކު، އަދި ކާކު)؛ ކޮންޓެކްސްޓް މަޢުލޫމާތު (އެ ތަފްސީރުކުރާ އެއްޗަކާއި އެއަށް ލިންކްކުރާ އެއްޗެހި، އަދި ތިޔަބޭފުޅާ އިތުރުކުރާ ކޮންމެ އެއްޗެއް)؛ އަދި ޕެކޭޖް ޑިސްކްރިޕްޝަނެއް. އާކައިވަށް ހަމައެކަނި ނިންމޭނެ ކަންކަން ހަމަ އެ ފޯމުގައި އަހާ — ޑެޒިގްނޭޓެޑް ކޮމިއުނިޓީ (ކުރިން ހުރި އެއްޗެއް ނުވަތަ އައު އެއްޗެއް) އާއި އޭގެ ޕްރިޒަވޭޝަން އޮބްޖެކްޓިވް، އެކްސެސް ރައިޓްސް — އަދި ނުދީފިނަމަ ދޫކޮށްލެވޭ، ދުވަހަކުވެސް ހަދައިގެން ނުލިޔޭ. ޕެކޭޖިންގ މަޢުލޫމާތު ލިބެނީ BagIt bag އާއެކު. ދެން AIP ގެ ޞަފްޙާއިން އަދިވެސް ނެތް އެއްޗެހި ދައްކާ. ކުރިން AIP އެއްގައި ހުރި ޑޭޓާ އޮބްޖެކްޓަކުން އޭގެ ބަދަލުގައި އެއަށް ލިންކް ކުރޭ.

އެޑިޓަރުން AIP އެއް ބިނާކުރޭ: އާކައިވަލް އިންފޮމޭޝަން ޕެކޭޖެއް ހަދައި، މި ގުޅުންތައް އެއްޗަށްފަހު އަނެއްޗެއް އިތުރުކުރޭ، ކުރިއަށް ދާއިރު ކޮންމެ ބައެއް ހަދަމުން. OAIS އިން ބޭނުންވާ ގޮތަށް، މަޢުލޫމާތު ވިސްނޭގޮތަށް ހުންނަން ޖެހެނީ ކާކަށްކަމާއި ކޮން ޓެސްޓްތަކަކުންކަން ވެސް ބުނޭ: ޑެޒިގްނޭޓެޑް ކޮމިއުނިޓީއެއް، އެ ޓެސްޓް ކުރެވޭ ޕްރިޒަވޭޝަން އޮބްޖެކްޓިވް(ތައް) އާ ގުޅިގެން، އަދި ޓްރާންސްފޯމޭޝަނަކުން އަގުތައް ސަލާމަތްވާން ޖެހޭ ކޮންމެ ޓްރާންސްފޯމޭޝަނަލް އިންފޮމޭޝަން ޕްރޮޕަޓީއެއް. މިއެއްޗެހި ކަނޑައަޅަނީ އޭޖެންޓެއް (އާންމުކޮށް އާކައިވް)، ޑެޒިގްނޭޓެޑް ކޮމިއުނިޓީއާ މަޝްވަރާކޮށްގެން، ކޮމިއުނިޓީ އަމިއްލައަށް ނޫން.

އެ ޗެކްކުރުން. AIP އެއްގެ ޞަފްޙާގައި ބޭނުންވާ ކޮންމެ ބައެއްގެ ޗެކްލިސްޓެއް ދައްކާ: ހުރި، ނެތް، ނުވަތަ (ޕެކޭޖިންގ މަޢުލޫމާތަށް) AIP އަކީ BagIt bag އެއްގެ ގޮތުގައި ބޭރަށް ލިޔުމުން ލިބޭ. ނެތް އެއްޗެހި އެޑިޓަރުން އިތުރުކުރޭ. ޞަފްޙާގައި AIP އާ ގުޅިފައިވާ ހުރިހާ އެއްޗެއް ވެސް ލިސްޓްކޮށްފައި، އަދި "ގްރާފުގައި ބަލާ" އިން މުޅި ޕެކޭޖް ދައްކާ.

ޕެކޭޖެއްގެ ގޮތުގައި ރައްކާކޮށްފައިވާ AIP އެއް. ގިނަ ފަހަރަށް ބައިތައް ތަފްސީލުކޮށްފައި ނުވަނީ އާކައިވުގައި އަމިއްލައަށް ނޫން، އެއްޗެހި ހުންނަނީ AIP ރައްކާކޮށްފައިވާ ޕެކޭޖުގެ ތެރޭގައި — މިސާލަކަށް Eternal އިން ހެދި AIP އެއް، .7z ނުވަތަ .zip ފައިލެއްގެ ގޮތުގައި ބަހައްޓާފައި، AIP ގެ ސްޓޯރޭޖް ލޮކޭޝަނުން ނަން ބުނެފައި. އޭރުން AIP ގެ ޞަފްޙާގައި އޭގެ ޕެކޭޖް AIP ގެ ބައިތަކާ މެޕް ކުރޭ ހުށަހަޅާ: އާކައިވުން ޕެކޭޖް ލިބިގަނެ، ހުޅުވައި، އޭގެ BagIt bag ޗެކްކޮށް (ކޮންމެ ފައިލެއްގެ ޗެކްސަމް، އަދި Payload-Oxum)، ކޮންމެ ބައެއް ޕެކޭޖުގައި ހުރި ތަނާއި އެތާގައި ބުނާ އެއްޗެއް ދައްކާ — އޭގައި ހިމެނޭ އަޕްލޯޑް ސްޕްރެޑްޝީޓް (metadata.csv، metadata_definition.xml ގައިވާ ކޮލަމް ތަޢުރީފުތަކާއެކު ކިޔާފައި)، METS ފައިލްގެ PREMIS (ކޮންމެ ފައިލެއްގެ ފޯމެޓް އޭގެ PRONOM އައިޑެންޓިފަޔަރާއެކު، އޭގެ ޗެކްސަމް، އަދި އިންޖެސްޓާއި ވައިރަސް ޗެކް ފަދަ ހާދިސާތައް)، ޗެކްސަމް އޮޑިޓް އަދި ޕްރިޒަވޭޝަން ޑިސްކްރިޕްޝަން މަޢުލޫމާތުގެ ފައިލް. ކޮންމެ ބައެއްގައި އެ ހިމެނެން ޖެހޭ އަޕްލޯޑް ސްޕްރެޑްޝީޓްގެ އެންޓްރީތައް ވެސް ލިސްޓްކޮށްފައި — Semantics (ގިނަ ފަހަރަށް ސިމެންޓިކް ރެޕްރެޒެންޓޭޝަން މަޢުލޫމާތު ހިމެނޭ ވަކި AIP އެއްގެ އައިޑެންޓިފަޔަރ، އެ AIP މި އާކައިވްގައި ތަފްސީލުކޮށްފައިވާނަމަ ލިންކްކޮށްފައި) އާއި Language؛ FixityHashSHA256؛ Provenance، Creator، Publisher އަދި Contributor؛ ކޮންޓެކްސްޓް މަޢުލޫމާތަށް Relation؛ އެކްސެސް ރައިޓްސް މަޢުލޫމާތަށް Rights؛ Format އާއި FormatInfo؛ OtherRI — އަދި ފުރާފައި ނުވާ އެއްޗެހި، އަދި އޭގެ ސަބަބު ބުނޭ: ހުސްކޮށް ބާއްވާފައި، ނުވަތަ ބޭނުންކުރި ސްޕްރެޑްޝީޓުގައި އެފަދަ ކޮލަމެއް ނެތް. އެހެނިހެން ރެޕްރެޒެންޓޭޝަން މަޢުލޫމާތަކީ އިޚްތިޔާރީ އެއްޗެއް. ތާވަލް CSV ގެ ގޮތުގައި ޑައުންލޯޑް ކުރެވޭނެ.

ޑިޖިޓަލް މަޢުލޫމާތު ހިފެހެއްޓުން: OAIS ގެ ތިން އުސޫލު

ބިޓްތައް ރައްކާތެރިކޮށް ބެހެއްޓުން ނުފުދޭ. ސޮފްޓްވެއަރ، ހާޑްވެއަރ، އަދި މީހުންނަށް އެނގޭ ކަންކަން ބަދަލުވާތީ، މަޢުލޫމާތު އޭގެ ޑެޒިގްނޭޓެޑް ކޮމިއުނިޓީއަށް — އެ ބޭނުންކުރެވެން ޖެހޭ މީހުންނަށް — އޭގެ ޕްރިޒަވޭޝަން އޮބްޖެކްޓިވްތަކުގައި ބުނާ ގޮތްތަކަށް މިނިވަންކޮށް ވިސްނޭގޮތަށް ހުންނަން ޖެހޭ. OAIS އިން އެކަން ހާސިލުކުރުމުގެ ތިން އަސާސީ ގޮތެއް ބުނޭ. ކޮންމެ އެއްޗެއް ތިރީގައި ތަފްސީލުކޮށްފައި، މި އެޕްލިކޭޝަނުގައި އެކަން ކުރާނެ ގޮތާއެކު.

1. ރެޕްރެޒެންޓޭޝަން މަޢުލޫމާތު އިތުރުކުރުން

ޑޭޓާ އޮބްޖެކްޓް ހުރި ގޮތަށް ބަހައްޓައި، އެ ވިސްނުމަށް ބޭނުންވާ ރެޕްރެޒެންޓޭޝަން މަޢުލޫމާތު އިތުރުކުރުން. ރެޕްރެޒެންޓޭޝަން މަޢުލޫމާތަށް ވެސް އޭގެ އަމިއްލަ ރެޕްރެޒެންޓޭޝަން މަޢުލޫމާތު ބޭނުންވޭ، ބާކީ ހުންނަ އެއްޗަކީ ޑެޒިގްނޭޓެޑް ކޮމިއުނިޓީއަށް ކުރިން ވިސްނޭ އެއްޗަކަށް ވަންދެން. ފުރަތަމަ ބޭނުންކުރަންވީ އުސޫލަކީ މިއީ: ޑޭޓާގެ އެއްވެސް އެއްޗެއް ބަދަލެއް ނުވާތީ، އެއްވެސް އެއްޗެއް ގެއްލިއެއް ނުދާނެ.

  • ރެޕްރެޒެންޓޭޝަން މަޢުލޫމާތު ހެދުން ގައި ބުނާ ގޮތަށް އެ ހަދާ: RepInfo ޓޫލްސްގައި ފޯމެޓްގެ ބިނާއާއި ކޮންމެ އެލިމެންޓެއްގެ މާނަ ތަފްސީލުކޮށް، އެހެން ކޮންމެ ރެޕްރެޒެންޓޭޝަން މަޢުލޫމާތެއް އެޑިޓަރުން އިތުރުކުރޭ.
  • އެ ފުދޭތޯ ޗެކް ކުރޭ: ބިޓްތަކަށް ސްޓޯރޭޖް ލޮކޭޝަނެއް ހުރި ޑޭޓާ އޮބްޖެކްޓެއް، ހަމައެކަނި އޭގެ ރެޕްރެޒެންޓޭޝަން މަޢުލޫމާތުގެ ތެރެއިން، ތާވަލެއް، ސްޕެކްޓްރަމެއް ނުވަތަ ފޮޓޯއެއްގެ ގޮތުގައި އޭގެ ޞަފްޙާއިން ހުޅުވޭނެ (ޑޭޓާ ބެލުމާއި ތަހުލީލުކުރުން ބަލާ). އެކަން ކުރެވިއްޖެނަމަ، ސޮފްޓްވެއަރަކަށް ޑޭޓާ ކިޔުމަށް ތަފްސީލު ފުދޭ.
  • އެ މި އެޕްލިކޭޝަނާ ނުބެހޭ ގޮތަށް ބަހައްޓާ: ޑޭޓާގެ ތަފްސީލު ޑައުންލޯޑް ކުރޭ އިން އެ ސްޓޭންޑަޑް ގޮތްތަކަށް (RDF، DFDL، Kaitai Struct، DRB) ބޭރަށް ލިޔޭ.

2. ޓްރާންސްފޯމޭޝަން

ރެޕްރެޒެންޓޭޝަން މަޢުލޫމާތު އިތުރުކުރުން ނުފުދޭނަމަ، ނުވަތަ ފޯމެޓެއް ބޭނުން ނުކުރެވޭ ހާލަތަށް ދާނަމަ، ޑޭޓާ އޮބްޖެކްޓް އެހެން ފޯމެޓަކަށް އަލުން ލިޔޭ. މިއިން ކޮންޓެންޓް މަޢުލޫމާތު ބަދަލުވާތީ، އެ ޗެކްކޮށް ރެކޯޑް ކުރަން ޖެހޭ: ސަލާމަތްވާން ޖެހޭ އަގުތައް ނިންމާ (އޭގެ ޓްރާންސްފޯމޭޝަނަލް އިންފޮމޭޝަން ޕްރޮޕަޓީތައް)، ޓްރާންސްފޯމޭޝަނަށްފަހު އެއްޗެހި ޗެކް ކުރޭ، އަދި ކުރި ކަމެއް ބުނާ ޕްރޮވެނަންސް މަޢުލޫމާތު އިތުރުކުރޭ. ނަތީޖާއަކީ AIP ވަރޝަނެއް، އަސްލުގެ ބަދަލުގައި ބޭނުންކުރެވިދާނެ އެއްޗެއް. އަނބުރާ ކުރެވޭކަން ދައްކައިނުދެވޭ ޓްރާންސްފޯމޭޝަނަކީ އަނބުރާ ނުކުރެވޭ ޓްރާންސްފޯމޭޝަނެއް، އެއިރު އެ ޗެކްތަކަކީ މުހިންމު އެއްވެސް އެއްޗެއް ނުގެއްލުނުކަމުގެ ހެކި.

  • ޑޭޓާ އޮބްޖެކްޓްގެ ޞަފްޙާ ހުޅުވައި ޓްރާންސްފޯމް… ހޮވާ. އޭގެ ބިޓްތަކަށް ސްޓޯރޭޖް ލޮކޭޝަނަކާއި، އެއްޗެހި ޑިކޯޑް ކުރުމަށް DFDL، DRB SDF ނުވަތަ Kaitai Struct ތަފްސީލެއް ބޭނުންވޭ.
  • މެޕްކޮށްގެން، އާކައިވްގައި: އައު ފޯމެޓް ހޮވާ — އާކައިވްގައި DFDL ތަފްސީލެއް ހުރި ކޮންމެ ފޯމެޓެއް (ބޭނުންނަމަ ފުރަތަމަ RepInfo ޓޫލްސްގައި އައު އެއްޗެއް ތަފްސީލުކުރޭ) — އަދި އޭގެ ކޮންމެ އެލިމެންޓެއް ހެދޭ ގޮތް ބުނޭ: ކުރީގެ ފޯމެޓްގެ އެލިމެންޓެއް ފެންނަ ކޮންމެ ފަހަރަކު އެއް ފަހަރު ތަކުރާރުކޮށް، ކޮޕީކޮށް (އިޚްތިޔާރީ ސްކޭލަކާއި އޮފްސެޓަކާއެކު، މިސާލަކަށް ޑިގްރީން ރޭޑިއަނަށް)، ގުނައިގެން، ނުވަތަ ސާބިތު އަގެއް. ފުރަތަމަ ލަފާއިން އެލިމެންޓްތައް ނަމާއި މާނައިން ދިމާކުރޭ؛ މެޕިންގ ލިޔުމެއްގެ ގޮތުގައި ވެސް އެޑިޓް ކުރެވޭނެ. ޗެކް ކުރާނެ ޓްރާންސްފޯމޭޝަނަލް އިންފޮމޭޝަން ޕްރޮޕަޓީތައް ހޮވާ، އަގުތައް ކުޑަކޮށް ބަދަލުވެދާނެނަމަ ޓޮލަރެންސަކާއެކު (މިސާލަކަށް މަދު ޕްރިސިޝަނަކުން ރައްކާކޮށްފައި).
    • ޓެސްޓް ކޮށްލާ: އައު ޑޭޓާ ލިޔެވެނީ އައު ފޯމެޓްގެ ތަފްސީލުން، ހަމަ އެ ތަފްސީލުން އަލުން ޑިކޯޑް ކުރެވި، ކޮންމެ ޕްރޮޕަޓީއެއްގެ އަގުތައް އަސްލުގެ އަގުތަކާ އަޅާކިޔޭ. ކޮންމެ އެއްޗެއް ހިފެހެއްޓުނުތޯއާއި، ޓްރާންސްފޯމޭޝަން އަނބުރާ ކުރެވޭތޯ ފެންނާނެ، އަދި އައު ފައިލް ޑައުންލޯޑް ކުރެވޭނެ. އެއްވެސް އެއްޗެއް ސޭވެއް ނުކުރެވޭ.
    • ޓްރާންސްފޯމް: އައު ފައިލް އާކައިވްގައި ރައްކާކޮށް، AIP ވަރޝަނެއްގައި (އަސްލު AIP އާ ގުޅިގެން) އައު ޑޭޓާ އޮބްޖެކްޓެއްގެ ގޮތުގައި ރެކޯޑް ކުރެވޭ، ފިކްސިޓީ މަޢުލޫމާތާއި (އޭގެ SHA-256 ޑައިޖެސްޓް) ޓްރާންސްފޯމޭޝަން ރެކޯޑްކުރާ ޕްރޮވެނަންސް މަޢުލޫމާތާއެކު — އެ ފެށުނު އެއްޗެއް، އެ ތަބާވި މެޕިންގ، ކޮން އިރަކުކަން، އަދި ކޮންމެ ޗެކެއް.
  • އެހެން އެޕްލިކޭޝަނަކުން: ޓްރާންސްފޯމޭޝަން ކުރަނީ ކޮންވަޓަރެއް، ސްކްރިޕްޓެއް ނުވަތަ އެހެން ޕްރޮގްރާމެއްނަމަ، ހަމަ އެ ޞަފްޙާގައިވާ "ނުވަތަ އެހެން އެޕްލިކޭޝަނަކުން ޓްރާންސްފޯމް ކުރޭ" ބޭނުންކުރޭ. ޑޭޓާއާއި އޭގެ ތަފްސީލު ޑައުންލޯޑްކޮށް، އެތާގައި ޓްރާންސްފޯމްކޮށް، ދެން ނަތީޖާ އަޕްލޯޑްކޮށް ކުރި ކަމެއް ފުރާ: އެޕްލިކޭޝަނާއި އޭގެ ވަރޝަން، ކުރީ ކާކުކަމާއި ކޮން އިރަކުކަން، ފިޔަވަޅުތައް ނުވަތަ ސެޓިންގްސް، ނަތީޖާ ތަފްސީރުކުރެވޭނީ ކޮންއެއްޗަކުންކަން، އެ އަނބުރާ ކުރެވޭތޯ، އަދި ކޮންމެ ޓްރާންސްފޯމޭޝަނަލް އިންފޮމޭޝަން ޕްރޮޕަޓީއެއްގެ ހާލު. ޕްރޮޕަޓީއެއްގެ އަގުތައް ދިޔައީ އައު ފޯމެޓްގެ ކޮން އެލިމެންޓަކަށްކަން ބުނެ، އާކައިވަށް ކުރީގެ އަދި އައު ޑޭޓާ ޑިކޯޑް ކުރެވޭނަމަ، އެއްޗެހި އާކައިވް އަމިއްލައަށް ޗެކް ކުރާނެ؛ ނޫންނަމަ ތިޔަބޭފުޅާ ރިޕޯޓްކުރާ އެއްޗެއް ރެކޯޑް ކުރާނެ. އެ މީހާއާއި އެޕްލިކޭޝަން ރެކޯޑް ކުރެވެނީ އޭގެ ޕްރޮވެނަންސް މަޢުލޫމާތުގައި.
  • ކޮންމެ ގޮތެއްގައި ވިޔަސް، އަސްލު AIP ގެ ރެފަރެންސް، ކޮންޓެކްސްޓް އަދި އެކްސެސް ރައިޓްސް މަޢުލޫމާތު AIP ވަރޝަނަށް ކޮޕީތަކެއްގެ ގޮތުގައި ގެނެވޭ (ރެފަރެންސް މަޢުލޫމާތުގައި އައު ޑޭޓާ އޮބްޖެކްޓްގެ ނަން ވެސް ހިމަނައިގެން)، އަދި އައު ޕެކޭޖް ޑިސްކްރިޕްޝަނަކުން އެއީ ކޮބައިކަމާއި އެ ހެދުނު ގޮތް ބުނޭ — އެހެންކަމުން އަސްލުގައި AIP އަކަށް ބޭނުންވާ ހުރިހާ ބައެއް ހުރިނަމަ، AIP ވަރޝަނުގައި ވެސް އެއްޗެހި ހުންނާނެ. އަސްލު ބާކީ ހުންނާނީ ހުރި ގޮތަށް.

3. ފުރިހަމަ AIP ތައް އެހެން އާކައިވަކަށް ހަވާލުކުރުން

މި އާކައިވަށް ބައެއް މަޢުލޫމާތެއްގެ ބެލެހެއްޓުން ނުކުރެވޭ ހާލަތެއްގައި، އެހެން އާކައިވަކަށް އޭގެ ޒިންމާ ނަގައިދެވޭނެ. އެކަން ކުރެވެނީ ކޮންމެ AIP އެއް ފުރިހަމަނަމަ ހަމައެކަނި — OAIS އާކައިވަލް އިންފޮމޭޝަން ޕެކޭޖެއްގެ ބައިތައް ގައި ލިސްޓްކޮށްފައިވާ ކޮންމެ ބައެއް — އެހެންކަމުން ބަލައިގަންނަ އާކައިވަށް އެއްވެސް ސުވާލެއް ނުކޮށް ކުރިއަށް ދެވޭނެ.

  • އެ ފުރިހަމަކަން ޔަގީންކުރޭ: AIP ގެ ޞަފްޙާއިން ހުރި ބައިތަކާއި ނެތް ބައިތައް ދައްކާ؛ ނެތް އެއްޗެހި އާކައިވާއެކު މަސައްކަތްކުރުން ގައި ބުނާ ގޮތަށް، އެޑިޓަރުން އިތުރުކުރޭ. ކުރިން އެހެން ތަނެއްގައި ޕެކޭޖްކޮށްފައިވާ AIP އަކަށް (މިސާލަކަށް Eternal އިން)، "އޭގެ ޕެކޭޖް AIP ގެ ބައިތަކާ މެޕް ކުރޭ" އިން އޭގެ ޕެކޭޖުގައި ހުރިހާ ބައެއް ހުރިތޯ ދައްކައި، އޭގެ bag ޗެކް ކުރޭ.
  • އެ ހަވާލުކުރޭ: AIP ގެ ޞަފްޙާގައި، BagIt ގެ ގޮތުގައި ޑައުންލޯޑް ކުރޭ އިން އެ BagIt bag އެއްގެ ގޮތުގައި (RFC 8493، zip ކޮށްފައި) ބޭރަށް ލިޔޭ، އާކައިވްތަކާއި ލައިބްރަރީތަކުން ކޮންޓެންޓް ބަދަލުކުރުމަށް ބޭނުންކުރާ ޕެކޭޖިންގ ފޯމެޓް. data/aip.ttl އިން AIP އާއި އެ ހެދިފައިވާ ހުރިހާ އެއްޗެއް OAIS އިންފޮމޭޝަން މޮޑެލްގެ ބަސްތަކުން RDF ގައި ތަފްސީލުކުރޭ؛ data/objects/ ގައި އޭގެ ޑޭޓާ އޮބްޖެކްޓްތަކުގެ ބިޓްތައް، data/descriptions/ ގައި ކޮންމެ ތަފްސީލެއް ފައިލެއްގެ ގޮތުގައި، އަދި data/ontologies/ ގައި ބަސްތައް ކަނޑައަޅާ އޮންޓޮލޮޖީތައް. SHA-256 މެނިފެސްޓްތަކުން ބަލައިގަންނަ އާކައިވަށް، ކޮންމެ BagIt ޓޫލަކުން، ކޮންމެ ފައިލެއް ފުރިހަމައަށް އަދި ބަދަލެއް ނުވެ ލިބުނުތޯ ޗެކް ކުރެވޭ.
  • ބޮޑު ޑޭޓާއަށް، ނުވަތަ ބަލައިގަންނަ އާކައިވަށް ހޯދޭނެ ތަނެއްގައި ކުރިން ރައްކާކޮށްފައިވާ ބިޓްތަކަށް، BagIt، ބިޓްތަކަށް ރިފަރ ކޮށްގެން އިން ބިޓްތައް bag އިން ބޭރުގައި ބަހައްޓައި، fetch.txt ގައި ލިސްޓް ކުރޭ، ފައިލްތަކަށް ރިފަރކުރުމުގެ BagIt ގެ ގޮތް: ކޮންމެ އެއްޗެއް ލިބޭނެ URL އާއި، bag ގައި އެ ދާނެ ތަން. މެނިފެސްޓްގައި ކޮންމެ ފައިލެއްގެ ޗެކްސަމް އަދިވެސް ހުރުމުން، އެއްޗެހި ލިބުމުން bag ފުރިހަމަވެ، ޗެކް ފާސްވާނެ.
  • bag އިން AIP ގެ ކޮންމެ ބައެއްގެ ނަން oais-aip-components.txt ގައި ބުނޭ — ކޮންމެ އެއްޗެއް ހުރިތޯ، aip.ttl ގައި އެއީ ކޮން އިންޑިވިޖުއަލުންތޯ، އަދި އެ ހިމެނޭ ފައިލްތައް — އަދި bag-info.txt އިން AIP ފުރިހަމަތޯއާއި ނެތް އެއްޗެއް ބުނޭ. bag އަކީ އަމިއްލައަށް ޕެކޭޖިންގ މަޢުލޫމާތު، އެހެންވީމާ އަމިއްލަ އެއްޗެއް ނެތް AIP އަކަށް bag ތަފްސީލުކުރާ އެއްޗެއް ލިބޭ.
  • މި އެޕްލިކޭޝަން ހިންގާ އާކައިވަކަށް /entities/import އިން AIP ގެ ތަފްސީލު ލޯޑް ކުރެވޭނެ.

ޑޭޓާ ބެލުމާއި ތަހުލީލުކުރުން

ބިޓްތަކަށް ސްޓޯރޭޖް ލޮކޭޝަނެއް ހުރި، އަދި ރެޕްރެޒެންޓޭޝަން މަޢުލޫމާތުން އެއްޗެހި ކިޔާނެ ގޮތް ބުނާ ޑޭޓާ އޮބްޖެކްޓެއް، އޭގެ ޞަފްޙާއިން ނުވަތަ ގްރާފުގައި އޭގެ ރައިޓް ކްލިކް މެނޫއިން ހުޅުވޭނެ:

  • އޭގެ ރެޕްރެޒެންޓޭޝަން މަޢުލޫމާތުގެ މެނިފެސްޓް (Turtle)، ޑޭޓާއާއި ކޮންމެ ތަފްސީލެއްގެ ނަން ސާފުކޮށް ބުނާ: TOPCAT (oais-structure-topcat ރީޑަރާއެކު، OAIS-RepInfo ފޯމެޓް) އާއި SPLAT އެ ހުޅުވަނީ އޭގެ އެޑްރެހުން.
  • އޭގެ ޑޭޓާ VOTable ގެ ގޮތުގައި (ތާވަލެއް ނުވަތަ ސްޕެކްޓްރަމެއް) ނުވަތަ FITS (ފޮޓޯއެއް)، ސާވަރުގައި އޭގެ ރެޕްރެޒެންޓޭޝަން މަޢުލޫމާތުން ޑިކޯޑްކޮށްފައި — ގިނަ އެޕްލިކޭޝަންތަކަށް ކިޔޭ ސްޓޭންޑަޑް ފޯމެޓްތައް.
  • "TOPCAT"، "SPLAT"، "DS9" ނުވަތަ "Aladin" އިން ބަލާ އިން ތިޔަބޭފުޅާގެ ކޮމްޕިއުޓަރުގައި ހިނގާ އެ އެޕްލިކޭޝަނަށް SAMP އިން ޑޭޓާ ފޮނުވާ (ޞަފްޙާއިން އެކަމަށް ހުއްދަ އެދޭނެ). Fiji/ImageJ އިން SAMP ބޭނުން ނުކުރޭ: އޭގައި FITS ފައިލް ހުޅުވާ، ނުވަތަ FITS ލިންކްގެ އެޑްރެސް ދޭ.
  • "TOPCAT ފައްޓާ" ނުވަތަ "SPLAT ފައްޓާ"، އެޕްލިކޭޝަންތައް އަމިއްލައަށް ޑައުންލޯޑްކޮށް، ފައްޓައި، ކަނެކްޓް ނުކުރަން ބޭނުންވާ ބޭފުޅުންނަށް: އާކައިވުން ޑައުންލޯޑްކޮށް، ޑޭޓާ ކުރިން ލޯޑްކޮށްގެން އެޕްލިކޭޝަން ފައްޓާ. އެކަމަށް OpenWebStart ބޭނުންވޭ، އެއް ފަހަރު އިންސްޓޯލް ކުރާ ހިލޭ ލޯންޗަރެއް (މިހާރުގެ Java ގައި ނެތް Java Web Start ގެ ބަދަލު): ލިންކުން .jnlp ފައިލެއް ޑައުންލޯޑް ކުރޭ، OpenWebStart އިން އެ ހުޅުވާ. އެޕްލިކޭޝަން ސައިންކޮށްފައިވަނީ އާކައިވްގެ އަމިއްލަ، އަމިއްލައަށް ސައިންކުރި ސެޓްފިކެޓުން: ފުރަތަމަ ފަހަރު، OpenWebStart އިން ޕަބްލިޝަރު ދައްކައި އެއަށް އިތުބާރު ކުރަންތޯ އަހާ — އަބަދު އިތުބާރު ކުރުން ހޮވާ، ދެން ފެށުމުގައި ސީދާ ދާނެ. މިކަން ހުށަހެޅެނީ ދޭން ބޭނުންވާ އެޕްލިކޭޝަން އާކައިވަށް ދީފައިވާނަމަ.
  • "ފޮޓޯ މިތާގައި ބަލާ"، ފޮޓޯއަކަށް: އާކައިވްގެ އަމިއްލަ ވިއުއަރ، ޞަފްޙާގެ ތެރޭގައި، އިންސްޓޯލް ކުރާނެ އެއްވެސް އެއްޗެއް ނެތި. ކޮންޓްރާސްޓް ސްޓްރެޗް (ލީނިއަރ، ސްކުއެއަރ ރޫޓް، ލޮގް، asinh)، ޑިސްޕްލޭގެ ހަދުތައް، ކުލަތަކާއި ޒޫމް ހޮވާ؛ ހިއްލުމަށް ދަމާ، ޒޫމް ކުރުމަށް މައުސް ވީލް ބޭނުންކުރޭ، އަދި ޕިކްސެލެއްގެ އަގާއި ޔުނިޓް ބެލުމަށް އެއަށް ޕޮއިންޓް ކުރޭ.
  • FITS ފައިލްތައް: ޑޭޓާ އޮބްޖެކްޓެއްގެ ރެޕްރެޒެންޓޭޝަން މަޢުލޫމާތުން އެއީ FITS (PRONOM x-fmt/383) ކަމަށް ބުނާނަމަ، އޭގައި ހުރި އެއްޗެއް ބެލުމަށް އޭގެ އަމިއްލަ ހެޑަރުތައް ކިޔައި، އޭގެ ތާވަލްތަކަށް TOPCAT، އޭގެ ފޮޓޯތަކަށް DS9 އާއި Aladin ހުށަހަޅާ — އެއްޗެހި ކިޔަނީ FITS ފައިލް އަމިއްލައަށް. "މި FITS ފައިލް އޭގެ ހެޑަރުތަކުން ތަފްސީލުކުރޭ" އިން، RepInfo ޓޫލްސް ގައި، ހާއްސަކޮށް އެ ފައިލަށް ރެޕްރެޒެންޓޭޝަން މަޢުލޫމާތު ހަދާ: އޭގެ ތާވަލްތަކުގެ ކޮލަމްތައް ބާވަތާއި، ނަމާއި، ޔުނިޓް، ސްކޭލް، އޮފްސެޓް އަދި ފިލް އަގާއެކު، އޭގެ ފޮޓޯތައް ޕިކްސެލް ރޯތަކެއްގެ ގޮތުގައި، އަދި އޭގެ ހެޑަރުގެ ކީވޯޑްތައް FITS ކީވޯޑް ޑިކްޝަނަރީ (FITS ސްޓޭންޑަޑް 4.0) ގެ މާނަތަކާއެކު. ސޭވް ކުރުމުން، އާކައިވް އަމިއްލައަށް އެ ޑިކޯޑް ކުރޭ: އޭގެ ތާވަލް ނަންދީފައިވާ ކޮލަމްތަކާއެކު VOTable ގެ ގޮތުގައި، އޭގެ ފޮޓޯ، އަދި އޭގެ އަގުތައް އެއް ފަހަރާ އެއް ޞަފްޙާ.
  • "އަގުތައް މިތާގައި ބަލާ"، ސާވަރަށް ޑިކޯޑް ކުރެވޭ ކޮންމެ ޑޭޓާއަކަށް: ކޮންމެ އަގެއް ޞަފްޙާގައި ޕްރިންޓްކޮށް، ބިޓްތަކުގައި އެ ހުރި ތަނާއި އޭގެ މާނައާއެކު (އޭގެ މާނަ، ކޯޑެއްގެ މާނަ، ޔުނިޓާއެކު ސްކޭލް ކުރެވިފައިވާ އަގެއް)، RepInfo ޓޫލްސްއިން ނަމޫނާ ފައިލެއްގެ އަގުތައް ޕްރިންޓްކުރާ ގޮތަށް — އެއް ފަހަރާ އެއް ޞަފްޙާ، ބޮޑު ފައިލަކުން ބްރައުޒަރު ފުރިނުގަތުމަށް. ރެޕްރެޒެންޓޭޝަން މަޢުލޫމާތުގައި އެތައް ލެންގުއޭޖެއްގެ ތަފްސީލު (DFDL، DRB، EAST...) ހުރިނަމަ، އެ ޑިކޯޑް ކުރާނެ އެއްޗެއް ހޮވާ.

ފެށުމުގައި ބުނެފައިވާ ފަދައިން، މި އެސްޓްރޮނޮމީގެ އެޕްލިކޭޝަންތައް ބޭނުންކުރަނީ، އެއީ ދުރުގައިވާ އާކައިވްތަކުން ޑޭޓާ ލިބިގަނެ، އެތައް މަސްދަރަކުން ލިބޭ މަޢުލޫމާތު ތަހުލީލުކޮށް، އަޅާކިޔައި، ގުޅުވުމަށް ހަދާފައިވާ އެޕްލިކޭޝަންތަކަކަށް ވާތީ؛ އޭގެ ބަދަލުގައި VOTable ނުވަތަ FITS ކިޔާ ކޮންމެ އެޕްލިކޭޝަނެއް ބޭނުންކުރެވިދާނެ. އެއްޗެހި ނެތްނަމަ: TOPCAT (topcat-full.jar) ނުވަތަ SPLAT-VO (splat-vo-<version>.jar؛ About SPLAT ބަލާ)، ކޮންމެ އެއްޗެއް java -jar އިން ހިންގާ؛ ފޮޓޯތަކަށް، SAOImage DS9، Aladin Desktop ނުވަތަ Fiji. RepInfo ޓޫލްސްގެ ޕްރިވިއު ޞަފްޙާއިން ލޯކަލް ޑޭޓާ ފައިލަކަށް ބަންޑަލެއް ވެސް ޑައުންލޯޑް ކުރެވޭ: ތިޔަބޭފުޅާގެ ފައިލާއި ކޮންމެ ތަފްސީލެއްގެ ނަން ބުނާ މެނިފެސްޓެއް، ޖެނެރޭޓްކުރި ތާވަލް ވިއުއަކާއި، ފޮޓޯއަކަށް ނަމަ، ފޮޓޯ ވިއުއަކާއެކު.

ތާވަލް، ސްޕެކްޓްރަމް ނުވަތަ ފޮޓޯ: ހުށަހެޅޭ ވިއުއަރުތައް

RepInfo ޓޫލްސްއިން ތިޔަބޭފުޅާގެ ޑޭޓާގެ ބާވަތެއް ނާހާ: ތިޔަބޭފުޅާ ތަފްސީލުކުރާ ބައިޓް ލޭއައުޓްގެ ސިފައިން އެ ހޯދައި، ޖަވާބު ވިއު ސްޕެސިފިކޭޝަންތަކެއްގެ ގޮތުގައި (im:ViewSpecification، im:viewKind "table" ނުވަތަ "image" އާއެކު) ޑޭޓާގެ ސިމެންޓިކް ރެޕްރެޒެންޓޭޝަން މަޢުލޫމާތުގައި ރައްކާކުރޭ. ހުށަހަޅާނެ އެއްޗެއް ނިންމުމަށް އާކައިވުން އެއްޗެހި އަލުން ކިޔާ.

  • ތާވަލް — ރޯތަކަކީ ރޫޓްގެ ސީދާ ތެރޭގައިވާ، ތަކުރާރުވާ (ކަނޑައަޅާފައިވާ ޢަދަދަކަށް ނުވަތަ ފައިލް ނިމެންދެން)، އަދި ކޮލަމްތަކެއްގެ ގޮތުގައި ދައްކާނެ ފީލްޑްތައް ހުރި ފުރަތަމަ ރެކޯޑް، މިސާލަކަށް ރޯއަކަށް އެއް reading ނުވަތަ star (ފޮޓޯއެއްގެ ޕިކްސެލް ރޯތައް ދޫކޮށްލެވޭ)؛ އެއްވެސް ތަކުރާރުވާ ރެކޯޑެއް ނެތްނަމަ، މުޅި ފައިލަކީ އެއް ރޯ. ކޮލަމްތަކަކީ އެ ރެކޯޑްގެ އެއް ފަހަރު ފެންނަ، ނަންބަރެއް ނުވަތަ ލިޔުމެއް ހިމެނޭ ފީލްޑްތައް، ކޮންމެ އެއްޗެއް އޭގެ ޔުނިޓާއި މާނައާއެކު. ތާވަލެއް ހުށަހެޅެނީ TOPCAT އަށް، އަދި ދެވެނީ VOTable ގެ ގޮތުގައި.
  • ސްޕެކްޓްރަމް — ވިއުގައި މަދުވެގެން ދެ ކޮލަމް، ހުރިހާ އެއްޗެއް ނަންބަރު ހުރި ތާވަލެއް (މިސާލަކަށް ވޭވްލެންގްތް، ފްލަކްސް، އެރަރ) SPLAT އަށް ވެސް ހުށަހެޅޭ. ލިޔުމުގެ އެއް ކޮލަމް ހުރުމުން TOPCAT ހަމައެކަނި.
  • ފޮޓޯ — ރޫޓްގެ ސީދާ ތެރޭގައިވާ، ތަކުރާރުވާ (ރޯއެއް)، އަދި ތަކުރާރުވާ ނަންބަރު ފީލްޑެއް ހަމަ އެކެއް (އޭގެ ޕިކްސެލްތައް، ތަރުތީބުން) ހިމެނޭ ރެކޯޑެއް. ޕިކްސެލް ފީލްޑްގެ ޔުނިޓާއި މާނަ ވާނީ ފޮޓޯގެ އެއްޗެއް. ފޮޓޯއެއް ހުށަހެޅެނީ DS9 އާއި Aladin އަށް، އަދި ދެވެނީ FITS ގެ ގޮތުގައި، ޔުނިޓް BUNIT ގައި، މާނައާއި އަސްލު ހެޑަރުގައި. ރޯތައް ބަހައްޓަނީ ޑޭޓާގައި ހުރި ތަރުތީބުން: ފުރަތަމަ ރޯއަކީ FITS ރޯ 1، މި ވިއުއަރުތަކުން އެ ދައްކަނީ ތިރީގައި.

އެއް ތަފްސީލަކީ ތާވަލަކާއި ފޮޓޯއެއް ވެސް ވެދާނެ. ކޮންމެ ވިއުއަރަކަށް، ސާވަރުން ޑޭޓާ ޑިކޯޑް ކުރާ DFDL ނުވަތަ DRB SDF ތަފްސީލަކާއި، ބިޓްތަކަށް ސްޓޯރޭޖް ލޮކޭޝަނެއް ބޭނުންވޭ. ވިއުތަކަކީ އާދައިގެ ވިއު ސްޕެސިފިކޭޝަންތައް ކަމުން، އަތުން ލިޔުނު ރެޕްރެޒެންޓޭޝަން މަޢުލޫމާތަށް އޭގެ އަމިއްލަ ވިއުތައް ދެވޭނެ. ޑިކޯޑް ކުރާއިރު ކޮންމެ ޕިކްސެލެއް އެލިމެންޓެއްގެ ގޮތުގައި ބިނާކުރާތީ، ވަރަށް ބޮޑު ފޮޓޯތައް ލަސް: 128 × 128 ފޮޓޯއަކަށް ސިކުންތު ކިހާވަރެއް ނަގާ.

ޑޭޓާ ޑިސްކްރިޕްޝަން ލެންގުއޭޖްތައް

RepInfo ޓޫލްސްއިން މަސައްކަތްކުރާ ކޮންމެ ޑޭޓާ ޑިސްކްރިޕްޝަން ލެންގުއޭޖަކާ ބެހޭ ނޯޓުތައް — ފޯމެޓެއް ތަފްސީލުކުރާ ގޮތް، މި އެޕްލިކޭޝަނުން ތަފްސީލުތައް ހިންގާ ގޮތް، ކޮންމެ އިންޖީނަކުން ރިޕޯޓްކުރާ އެއްޗެއް (ބާވަތާއެކު އަގުތައް، ބައިޓްގެ ތަންތަން)، އަދި އޭގެ އެނގިފައިވާ ހަދުތައް:

  • DFDL — Open Grid Forum ގެ Data Format Description Language، Apache Daffodil އިން ހިންގާ.
  • DRB — GAEL ގެ Java Data Request Broker އާއި އޭގެ SDF ސްކީމާތައް.
  • EAST — CCSDS ގެ ޑޭޓާ ޑިސްކްރިޕްޝަން ލެންގުއޭޖް، އެލިމެންޓް ޓްރީއަށް ކިޔައި، އެއިން ލިޔެ، އަދި ސީދާ ތަފްސީރުކުރެވޭ.
  • Kaitai Struct — ކުރިން ޕާސަރ ކޯޑަކަށް ކޮމްޕައިލް ކުރެވޭ .ksy ތަފްސީލުތައް.

ޑިވެލޮޕަރުންނަށް ޑޮކިއުމެންޓޭޝަން

Javadoc API ރިފަރެންސް → — މި ކޯޑްބޭސްގެ އަމިއްލަ /** ... */ ސޯސް ކޮމެންޓްތަކުން ޖެނެރޭޓްކޮށްފައި (mvn javadoc:javadoc)، މި ހިނގަމުންދާ އެޕްލިކޭޝަނުގައި ހިމަނާފައި، އެހެންކަމުން ހަގީގަތުގައި ޑިޕްލޮއި ކޮށްފައިވާ ވަރޝަނާ އަބަދުވެސް އެއްގޮތް. އޭގައި މި އެޕްލިކޭޝަނާއި، OAIS ކޯރ މޮޑެލް (oaiscore)، އަދި OAIS ސްޓްރަކްޗަރ އެޑަޕްޓަރުތައް (oais-structure-*: DFDL، Kaitai Struct، DRB، TOPCAT އަދި ޑެމޯ) ހިމެނޭ، ވަކިވަކި ޓެބްތަކުގެ ދަށުގައި.

އޮންޓޮލޮޖީތަކުގެ ސޯސް ފައިލްތައް ފުރަތަމަ ޞަފްޙާއިން ޑައުންލޯޑް ކުރެވޭނެ، ފެށޭއިރު ލޯޑްކުރެވޭ ގޮތަށް ބައިޓަށް ބައިޓް. ފުރިހަމަ ތަސައްވުރަށް — ސްޓޯރޭޖް، ލޮގިން މޮޑެލް، ސްކޭލްގެ ހަދުތައް، އިންޓަނޭޝަނަލައިޒޭޝަން، އޮންޓޮލޮޖީތައް އަޕްޑޭޓް ކުރާނެ ގޮތް — ޕްރޮޖެކްޓްގެ README.md ބަލާ.
