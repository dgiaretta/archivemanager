Format: DFDL by hand

Write the DFDL description yourself, for what the editor's element tree can't express — checksums, encryption, other compression, records spread over several lines, and anything else the language can do. Once saved, it replaces the generated description in the preview, the sample test, the download and when saving to the archive. The element tree still provides the meanings (semantic names, units, codes) saved as Semantic Representation Information, but a sample test of a hand-written description shows the engine's own tree rather than lining it up with the element tree.

A sample test runs the description inside this application, so it's checked first: no DOCTYPE or files included from elsewhere (DFDL may include Daffodil's own built-in schemas); for Kaitai Struct, no imports or custom process: routines (zlib, xor, rol and ror are built in); for DRB, no queries calling Java or reading files.

The element tree has changed since this was written, so what it generates now is different. Check whether the hand-written description needs the same change.
