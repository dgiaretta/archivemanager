Format: DFDL by hand

Write Python code for the generated drb-python driver to call, for what the element tree can't express.

  • prepare(data)
  • check(root)
  • metadata(root)
  • restore(data)

root.original_bytes are the file's bytes.

An add-in is Python code, which runs with the full rights of whoever uses the driver. It's checked to be valid Python, but it can't be checked to be safe. This server runs add-ins in sample tests. This server doesn't run add-ins in sample tests (archive.drb-python.run-hand-written-add-ins), so test the downloaded package elsewhere.
