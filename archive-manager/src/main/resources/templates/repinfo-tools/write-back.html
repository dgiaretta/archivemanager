Write back

Decodes a sample file, then writes it back with the description above and compares the two. With no changes this is a round trip: identical bytes mean the description is enough to re-create the file from its decoded values. To write a changed file, give changes as path = value lines, e.g. /header/count = 3, naming elements as in the test above (/sample[2] for the second of a repeated element). Counts and lengths have to be changed to match. note
