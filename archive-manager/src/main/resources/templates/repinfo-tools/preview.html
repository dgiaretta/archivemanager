DRB — Python (drb-python)

A complete drb-python driver for this layout: the download is an installable package — install it with pip install drb-driver-am-format.zip — whose topic signature lets drb pick it automatically for files you open with it explicitly (no file extensions are set in the details above)files ending in fits. Each field becomes a child node carrying its byte offset/length and its semantic name, definition and units. The driver module is shown below.

The package also registers four drb-python add-ons, giving a decoded file's meaning as a whole and writing it back: am_format_semantics (every value with its meaning), am_format_metadata (semantic name → value), am_format_checks (values outside their valid range or code list, and bytes not covered) and am_format_write (the file written back, with any changes), e.g. node.get_impl(dict, "am_format_metadata").

With an add-in written by hand, as addin.py in the package. Edit it.

Open in TOPCAT or SPLAT

A zip with everything TOPCAT (with the oais-structure-topcat reader) or SPLAT (with oais-structure-splat) needs to open your data: a Representation Information manifest (Turtle) naming the data file, the DFDL and DRB SDF descriptions — either will do — a table view generated from the element tree (the first repeated record as rows, its fields as columns, with their units and meanings), and what each element means. Every file is named in the manifest, so they can be renamed or moved by editing it. Put your data file next to the manifest, under the name you give here.

Creates Structure/Semantic Representation Information linked to a Data Object, the same way the rest of the archive models any format's Representation Information. Pick which of the generated descriptions above to keep as Structure Representation Information — the field semantics are saved either way, as one Semantic Representation Information individual per field/row (semantic name as its rdfs:label, definition as its skos:definition, units linked via rico:hasUnitOfMeasurement), gathered under one overall Semantic Representation Information for the description as a whole.
