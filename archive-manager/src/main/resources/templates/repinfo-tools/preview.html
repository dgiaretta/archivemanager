DRB — Python (drb-python)

A complete drb-python driver for this layout: the download is an installable package — install it with pip install drb-driver-am-format.zip — whose topic signature lets drb pick it automatically for files you open with it explicitly (no file extensions are set in the details above)files ending in fits. Each field becomes a child node carrying its byte offset/length and its semantic name, definition and units. The driver module is shown below.
