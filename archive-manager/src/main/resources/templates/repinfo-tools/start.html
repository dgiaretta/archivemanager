FITS

Primary header + data unit, pre-populated with the FITS Standard's required keyword cards (SIMPLE, BITPIX, NAXIS...) and their real meanings.

HDF5

A worked-example logical schema (group/dataset/attribute) to replace with your own tree -- HDF5 has no fixed universal layout to template byte-for-byte.

Telemetry packets

A worked binary example using counts, a choice on a packet type, a length-prefixed message, a conditional checksum, and scaled values with units and code lists.

CSV table

Delimited text: one comma-separated reading per line to the end of the file, with units, a scale factor, a valid range and a fill value on its columns.

Or describe data whose format is already known

For a spreadsheet or delimited text, whose structure is defined by a published specification and which software already reads: describe only what each column means. It's saved as Semantic Representation Information, used together with a format profile (Structure Representation Information) and the software that reads the format (Other Representation Information: any one of several applications), or with Representation Information already in the archive.

Byte-layout format

A sequential binary format (like FITS): define fields in file order, each with a type, length, byte order, semantic name, definition, and units. Generates Kaitai, DFDL, and DRB.

Logical schema (HDF5-style)

A self-describing container's group/dataset/attribute tree: define the shape, semantic name, definition, and units of each part. Generates DRB and semantic documentation, not Kaitai/DFDL.
