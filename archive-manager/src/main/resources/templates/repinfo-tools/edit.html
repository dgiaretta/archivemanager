Structure

The file as a tree, in data order. A record groups elements (and can be repeated, or be one line of delimited text such as a CSV row); a field is one value; a choice is one of several records, picked by an earlier field's value. Counts, lengths and conditions can use earlier fields and arithmetic, e.g. n, rows * cols, flags = 1.
