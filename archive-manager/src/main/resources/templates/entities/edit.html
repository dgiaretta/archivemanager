Properties (literal values)

The OAIS Information Model, as modelled here, has no plain-text properties of its own — every OAIS property links one class to another (e.g. Access Rights Information, Data Object), so none appear in the dropdown below. Use Common (RDFS) → rdfs:comment to attach a description to an OAIS entity instead (that's what the bundled sample data does), or add a genuine OAIS relationship under Relationships below.

Some properties have a documented correspondence to the other ontology (e.g. rico:technicalCharacteristics → OAIS Other Representation Information) — hover an option in the picker below to see it, and it'll show inline once added.
