Byte-layout format

A sequential binary format (like FITS): define fields in file order, each with a type, length, byte order, and meaning. Generates Kaitai, DFDL, and DRB.

Logical schema (HDF5-style)

A self-describing container's group/dataset/attribute tree: define the shape and meaning of each part. Generates DRB and semantic documentation, not Kaitai/DFDL.
