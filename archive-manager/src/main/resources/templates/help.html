Help

A quick tour of the main things this app does. For the full picture — storage, the login model, scale limits, internationalisation, how to update the ontologies — see this project's README.md in the repository root; it goes well beyond what's summarised here.

1. Browse, no login needed

Catalogue and Accession Register are public search/browse views. From any record, Records, Agents, Provenance events, and Mandates link to each other (an agent's page lists what it created, and so on).

2. See a record's OAIS mapping

Open any record and follow its "OAIS mapping" link. The top half shows which OAIS classes correspond to the record's RiC-O type(s), read live from the bridging ontology; the bottom half, if the record has one, shows the actual linked OAIS preservation-description structure (Information Object → Data Object → Bit, and so on).

3. Explore the interactive graph

Graph shows the whole archive as a network; "View in graph" on any record/agent/activity/mandate page shows a focused view around just that one, with an adjustable depth. Double-click a node to open its detail page, right-click for a menu of its links (its detail page, and any external URL-valued property it has, like an rdfs:seeAlso). The checkboxes above the graph highlight nodes/edges by entity type, property, or relationship type — whatever's actually present in the currently-loaded graph.

4. Query it directly

SPARQL console runs arbitrary SELECT queries against the union of the data and ontology graphs — useful for answering a question none of the built-in pages happen to show, or for exploring the ontologies themselves.

5. Log in to create or edit anything

Everything above is read-only and needs no account. Log in with the shared edit password to unlock:

  • Entities — the generic editor. Create an individual of any RiC-O or OAIS class, then add its types, literal properties, and relationships one at a time. /entities/import (linked from that page) bulk-loads a pasted Turtle document instead.
  • Bulk Upload Spreadsheet (linked from the Catalogue page) — import a CSV/XLSX of NAM-format records in one go.
  • Format description tools — a guided editor for building Kaitai Struct, DFDL, and/or DRB descriptions of a binary or self-describing data format (built-in FITS and HDF5 starting points), saved into the archive as real Structure/Semantic Representation Information.
